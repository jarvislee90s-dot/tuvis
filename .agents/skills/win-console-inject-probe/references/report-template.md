# 规格定案表与报告模板（P7 产出）

## 单工具规格定案表（注入引擎直接消费的形态）

```markdown
## <工具名> <版本> · Windows 注入规格（<日期>，探测人/agent）

| 项 | 定案 | 证据 |
|---|---|---|
| 族 | A（RAW_VT 0x0208）/ B（crossterm 0x01F0）/ 新族：<模式值> | P1 日志 |
| 宿主 | conhost ✅/❌ · WT ✅/❌（不通注明现象） | P3 |
| 分块基线 | 80 字符/50ms/回车 150ms（或有修订，注明） | P3 |
| 回车/控制键 | VK 形态（统一）；字符形态 <可用/被丢> | P4 |
| 方向键 | <VT 原子批 / VK 形态（按家分支）> | P5 |
| bracketed-paste | <可用 / 禁用> | P5/E6 |
| busy 期语义 | <入草稿排队 / 即时消费 / 丢弃>；插队 <可/不可> | P6 |
| 长度 | 万字符 <耗时>，全量精确到达 <是/否 + 例外> | P3 |
| 会话文件确认路径 | <该工具会话文件位置模式> | P2 |
| 已知修剪/例外 | <尾空格/尾字符偶失等，按 TUI 语义归一口径> | P3 |
| 判定 | GO / GO-with-branches（列分支）/ PARTIAL（列限制）/ NO-GO（列证据） | — |
| 复验触发 | 大版本升级（<当前版本> → ?） | — |
```

## 判定口径

- **GO**：全规格通，无按家例外。
- **GO-with-branches**：主规格通 + 少量按家分支（常态——A/B 族天然带分支）。
- **PARTIAL**：部分长度档或宿主不可达（注明哪格、什么现象、剩余可用面）。
- **NO-GO**：无法建立可靠注入（必须有故障类别证据：写入层/缓冲层/消费层哪一层、什么现象）。

## 报告骨架（归档版）

1. 环境基线（OS/PS/WT/CLI 版本、会话拓扑、PID 台账）
2. 规格定案表（上表）
3. 与已知族的差异点（若无差异一句话即可）
4. 异常与开放问题（冻结/修剪/未复验项，如实标注）
5. 证据索引（日志 run-id 清单、截图、会话文件 stamp 路径）
6. 偏差登记（取样数不足、宿主覆盖不全等——如实写，不补痕迹）

归档位置：兔维斯 项目 `docs/research/refs/phase2-消息注入/`（命名 `<日期>-<工具>-windows注入规格.md`）；其他项目入用户指定目录。探测原始材料（日志/截图）留探测目录不删。
