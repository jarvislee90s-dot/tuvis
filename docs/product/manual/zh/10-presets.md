# 预设组

把一组资源变成开关——一条命令备好一整套写代码环境，用完一键还原。

## 预设是什么

预设组是一份命名的快照：挑选若干 Skill、MCP 服务器与插件组合在一起，之后**一键应用**到任意工具，也能一键**恢复默认**。

- **独占语义**：应用预设后，该工具只会看到「预设内资源 + 常驻资源」——预设外的技能链接会被自动断开，因此预设之间是干净切换，不是叠加；
- **基底快照**：工具处于无激活预设状态时首次应用，兔维斯先拍下当前完整状态作为基底；会话内切换沿用同一基底；「恢复默认」精确回到本次会话起点（暂存的移回、多开的清掉），下次应用时重拍；
- **常驻资源不触碰**：工具内建原生技能、原生 MCP 配置段与工具自装插件**定义上即常驻**——不进快照、不被暂存、不可启停；你也可以把任意「工具 × 资源」标成常驻，独占模式永不触碰；
- **两类预设**：通用预设（纯资源组合，可应用到任意工具）与工具私有预设（绑定单一工具，还能额外收录该工具的原生技能）。

应用时，非常驻的**原生技能**（真目录，非兔维斯链接）会被**移入暂存区** `~/.tuvis/stash/<工具>/skills/`（stash_journal 记账，崩溃可恢复）；恢复时逐条移回原位，原位被同名占位且内容不同则留下并如实列出，待人工处理。

## 创建、应用与恢复

![新建预设组：选类型、命名、勾选资源](../img/preset-create.png)

1. **创建**：在预设区新建预设，勾选想要的 Skill / MCP / 插件组合；选到需要绑定工具的内容时，界面会自动建议转为工具私有类型；
2. **应用**：对目标工具一键应用，兔维斯自动适配各工具的配置格式。默认是独占模式；启用时失败的部分不会回滚已成功项，冲突（已存在的资源）会被跳过并报告；
3. **恢复**：点「恢复默认」（或对预设执行取消），回到应用前的状态并销毁基底快照；
4. **切换其他预设**：会话内直接切，基底不变、状态对齐新预设。

## 托盘直开直关

系统托盘菜单里有「预设」子菜单：每个预设一个开关项，**勾上即应用、取消勾选即恢复**，不用回到主窗口。

> 💡 想让某份技能在任何预设下都保持在场？把它标成常驻，而不是塞进每个预设。

## 健康体检

预设应用依赖三层链接与账本一致：切换或恢复异常时，到资源 tab 的「一致性体检」卡片查看漂移分组并一键处置（详见「资源管理」一章）。
