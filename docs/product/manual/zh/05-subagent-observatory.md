# 子 Agent 观察台

主会话派发的后台子 Agent 从此不再是黑盒：名字、时长、token 与完整执行过程实时可见。

![手机看板里的子 Agent 清单](../img/subagent-mobile.png)

上图：手机看板（`/m`）中某 Claude 会话的「子 Agent」面板——清单按派发序排列，每个子 Agent 带名字、任务标题、时长与 token 消耗。

## 运行 chip：详情页里的实时小条

进入一个会话的详情页，正在运行的子 Agent 会以 chip 形式出现在消息区下方，内容是 **名字 + 时长 + token 消耗**。活跃子 Agent 的时长持续走字；完成后定格，数字冻结在原地。点 chip 即可直达它的执行过程详情。

## 「子 Agent」看板

会话详情里「子 Agent」看板与文件面板平级：

- 单一清单，按**派发顺序**排列，不混页不折叠；
- 绿点 = 活跃（时长 / token 走字），灰点 = 完成（定格）；
- 点清单卡片，进入该子 Agent 的执行过程详情。

## 执行过程详情

每个子 Agent 的详情对话框呈现四段内容：

1. **任务原文**——主会话派发时的原始任务；
2. **思考过程**——默认折叠，需要时展开；
3. **工具调用与结果**——折叠为单行，可逐条展开；
4. **输出正文**——该子 Agent 的最终产出。

活跃期间每 5 秒自动刷新一拍并贴底跟随；完成后定格为快照，随时回看、不再变化。

> 💡 子 Agent 悄悄挂死的最直接征兆：时长还在走字、输出却不再更新——回主会话终端看看吧。

## 回报提醒开关

「子 Agent 回报提醒」默认开启：子 Agent 完成回报、唤醒主会话时同样弹提醒。不想被吵？到「设置 → 通知与桌宠」把该开关关掉即可独立静默——主会话自身的提醒不受影响。

> 💡 当前版本（v1）的完整执行过程仅覆盖 Claude（经典任务通知与 teammate 空闲通告两套机制均已识别）；其余工具照常显示子 Agent 清单与运行 chip，执行详情暂不支持。
