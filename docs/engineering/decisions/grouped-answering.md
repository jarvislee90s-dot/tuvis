# 分组答题裁决

## 2026-10-27 · 同组多题只显示一张卡，一次提交

- 背景：逐题独立提交会把同一次发题拆成多次回合，且移动端难以核对整组。
- 决定：同一次原生多题请求/同一次异步发题组成一个答题组；逐题填写、内存暂存、最后一次提交整组；不同发题批次不拼批。
- 后果：翻题不提交；最后一题一次提交；审批决策不并入问答组。
- 状态：active。来源：`specs/2026-10-27-Codex兼容可用性与分组答题修正要求.md` B04/B05。

## 2026-10-28 · 已答组自动核销，不再要求核对

- 背景：投影已经 `answered`（正文已有正式回答）时，旧卡仍因本机 action 锚保留，堆在底部。
- 决定：全部成员 answered → 清 action 锚并退出停靠区，不再显示“核对结果”；已答组即使有旧锚也隐藏。
- 后果：只有真正未决/未答组保留卡；刷新不复活。
- 状态：active。

## 2026-10-28 · 恢复旧稿必须可见，不能提交隐形答案

- 背景：旧选项被新题移除后，恢复旧稿可能只设置 selected、当前 UI 不显示，却仍提交旧标签。
- 决定：旧选项仍存在才恢复为选中；已移除则落到可见自由输入；`selected` 不属于当前 options 时不得作为答案。
- 后果：“看见什么就提交什么”；旧稿恢复不绕过当前题身份。
- 状态：active。

## 2026-10-28 · 答案模式互斥：选项与自由文本只保留一个有效答案

- 背景：先填自由文本再点选项，实际提交仍可能使用旧文本。
- 决定：点选项清自由文本；输入自由文本清可见选项；两者不能同时作为有效答案。
- 后果：POST 内容必须与当前可见模式一致；返回上一题保留已选模式。
- 状态：active。

## 2026-10-28 · 已提交 Unknown 只读核对，无锚 Unknown 不展示

- 背景：远端无法证明已提交动作的最终结果，且用户已撤下历史/正文入口。
- 决定：本机有 action 锚的 Unknown 组保留只读核对；无锚 Unknown 不展示；不自动重发、不伪造取消/已答。
- 后果：核对失败不产生第二帧；历史入口不恢复。
- 状态：active。
