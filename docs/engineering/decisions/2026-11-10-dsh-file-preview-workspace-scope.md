日期：2026-11-10。状态：**部分被取代（2026-11-12 §0.2〔D22〕）**。

> **取代说明（2026-11-22 复核）**：本文关于「敏感路径规则」的收窄部分已被
> [`docs/MASTER-PLAN.md`](../../MASTER-PLAN.md) §0.2〔D22〕（2026-11-12 用户在场裁决）取代。
> D22 明确「文件预览取消目录准入限制，本人可预览系统允许 Tuvis 进程读取的普通文件，
> 不按项目目录、用户主目录、临时目录或所谓敏感目录的黑白名单再次拒绝」。因此本文中
> 「主目录外凭据根一律拒绝」「敏感目录段匹配拒绝」等条款**不再生效**；`SENSITIVE_DIRS`
> 表仅由创建域（`inject/create_path.rs`）按其自身策略消费。
> 仍然有效的部分：项目内外预览范围、配对设备门禁、会话身份核验、只读语义、路径归一、
> 大小上限、操作系统权限，以及上传仍受主会话与真实 cwd 约束。
> 该冲突在 2026-11-22 合并 `origin/main` 时被发现，并按用户在场裁决统一为 D22。

原始裁决（历史记录；其中「敏感路径规则」部分已被 D22 取代）：DSH 保留兔维斯通用的项目内外文件预览范围，沿用配对设备门禁、会话身份核验、只读、路径归一、敏感路径规则、大小上限和系统权限。普通桌面、下载、文档和临时目录的文件可以沿该入口预览。相对路径以会话 cwd 解析，绝对路径以实际落点为准。上传仍由服务端按主会话和真实 cwd 约束到项目附件目录。

## 当前八工具行为

共享 `/m/api/v1/file` 按快照定位唯一会话，DSH 携带实例 ID，之后调用同一个 `read_file_safe`。文件面板从工具读写、用户附件和正文路径提取条目。正文产物还要满足文件存在与可预览类型条件。直接预览接口接受未出现在列表中的路径。可读范围取决于共享读取规则，工具差异主要在会话解析和产物来源。

| 工具            | 项目外产物来源与配置目录现状                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude          | 会话引用可出现在列表。主目录内 `.claude` 受限，`.claude/plans` 有产物豁免。                                                                       |
| Codex（含 App） | 会话引用之外，列表合并本地图片和生成图。主目录内 `.codex/plans`、`.codex/generated_images` 有产物豁免。CLI rollout 能提供正文相对路径所需的 cwd。 |
| OpenCode        | 文件来自会话引用。`.local` 本身未列入拒绝清单，`.config` 受限。                                                                                   |
| OpenClaw        | 有可读 ACP replay 时可从会话引用提取文件。缺库、表或会话记录时列表无来源。`.openclaw` 本身未列入拒绝清单。                                        |
| Kimi            | 会话引用可出现在列表。`.kimi-code` 受限，`agents/main/plans` 序列有产物豁免。                                                                     |
| WorkBuddy       | 文件来自会话引用。`.workbuddy` 本身未列入拒绝清单。                                                                                               |
| ZCode           | 列表另外提取附件和 artifact。主目录内 `.zcode` 受限，当前无专门 artifact 豁免，条目可见时仍可能预览被拒。                                         |
| DSH             | 按已核验实例读取会话和文件引用。主目录内 `.dsh` 受限，普通项目外路径按通用规则处理。                                                              |

表中豁免是共享读取规则。工具名前缀表示典型产物来源。可读普通文件还受应用进程权限与文本 500 KiB、图片 5 MiB 上限约束。Windows 主目录下 `AppData` 整体受限，位于其中的用户临时目录也会受到影响。

代码依据见 `src-tauri/src/remote/api.rs` 的 `session_files`、`read_file`，`remote/files.rs` 的 `read_file_safe`、`EXEMPT_SUBPATHS` 和 `extract_file_paths_with_env`，以及 `remote/content.rs` 的八工具消息分派。

## 安全规则与验收

主目录基准有效时，现有黑名单只检查主目录内的规范路径。项目 `.env`、未列出的工具数据根、主目录外的自定义凭据根可能通过。计划产物的路径序列豁免也没有限定扩展名和具体工具数据根。这些属于现有保护盲区。安全修补应定位实际敏感根和明确的凭据文件，并将豁免限于已确认的产物子树。普通桌面、下载、文档和临时目录继续按通用规则读取。

A05 分别验收预览和上传。预览验证配对门禁、会话与实例匹配、项目外普通文件、现有敏感路径拒绝和大小上限。上传验证服务端 cwd、同一主会话、附件目录归属和路径逃逸拒绝。H14 使用隔离目录和合成文件验证这些边界。
