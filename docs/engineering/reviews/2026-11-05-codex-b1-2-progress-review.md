## 2. 本轮新增的确定性阻塞

真实 crate 的 `ThreadMirror.apply/project` 临时集成测试：

```text
b1_review_two_invalidations_must_not_revive_w1
  FAILED: left Answered / right Unknown
b1_review_same_patch_replacement_must_retire_old_w1
  FAILED: left Answered / right Unknown
```

前者是用户提出的 Q0/W1→Q1/W2→Q2/W1 序列；后者在同一 patch 中改题并替换 W1，再恢复 W1。两个用例编译成功并运行到状态断言，故已从“源码与模型反例”升级为“真实 Rust 行为红测”。

根因位置为 `mirror.rs` 的单值 `invalidated_answers`、新 witness 到来时 remove，以及遗漏同 patch 替换的失效条件。两条都属于 B1.2 当前状态机问题，不据此推翻已验收的 B1.1。

临时测试源已删除，三份受保护源码的前后 hash 一致；本轮规划没有修产品代码。上述不是修改后的绿测或完整 UI 端到端验收。

## 4. 本批范围边界

本批不新增跨进程持久撤销 journal；现有五列只存最近 witness。当前运行已知撤销不因 owner/snapshot/镜像释放遗忘，但跨进程重启仍按既有设计重新取证，不承诺识别前次进程所有已撤销来源。

如果要求重启后也拒绝所有历史重放，需要另外保存撤销信息，不能靠最近 witness 或总 hash 补出不存在的数据。该更强目标不被偷偷加入本轮验收。
