- T02：`CaptureScope { capture_generation, owner_epoch, owner_generation, host_key, thread_key }`；`CaptureClock { mono_ns, wall_ms }`。`BodyFrame { scope, revision, clock, changes: Vec<BodyChange> }`，变化只包含 `Baseline`、`EmptyItem`、`Append`、`InvalidatedItem`、`TurnTerminal` 五类；EmptyItem 携完整 turn/item 身份与冻结的 model/channel，Append 携 turn/item 身份和正文增量，TurnTerminal 携 turn 和权威状态；Baseline/InvalidatedItem 不得把已有正文当新输出。
- T02：`BodyObserver::on_frame(frame: BodyFrame) -> Vec<FinishedBody>`；`invalidate(scope: &CaptureScope)`。`FinishedBody` 仅在内存携带完整正文、冻结身份、参考配置、F/L、结束墙钟、短窗口标记和捕获代际，成功收尾才返回。
- T03：`FollowPurpose::{Remote,TokenizerEstimate}`；`DesktopIpcAdapter::acquire_following(key: &ThreadKey, purpose: FollowPurpose) -> Result<FollowLease, ProtocolError>`；`FollowLease::release()` 幂等；`subscribe_body_events()` 提供单个估算消费者的有界接收口。旧 `ensure_thread/unfollow` 调用语义保留，但 Remote 持有／释放统一经过用途仲裁。
- T04：`EstimateFact` 只含稳定脱敏的 host/thread/turn/item、model/channel、model_source、reference_profile_id、参考 Token 数、D、L 墙钟、捕获 runId、来源 build 和质量；不含正文。`commit_estimate(conn: &mut Connection, fact: &EstimateFact, permit: &CapturePermit) -> Result<bool, UsageError>` 只能在当前有效捕获许可下执行；CapturePermit 不是可脱离运行时门的旧布尔快照。`set_estimate_enabled(enabled: bool) -> Result<(), UsageError>` 只控制此来源，设置持久键为 `tps_state` 的 `tokenizer-estimate:enabled`，缺省 true；总授权另行取现有 usage.enabled，两者共同决定许可。
- T05：`SpeedMetricMode::TokenizerEstimate` wire 固定为 `tokenizer-estimate`；`TimingMethod::IpcBodyReference` wire 为 `ipc-body-reference`。公共 SeriesKey 增 `referenceProfileId: string|null`，旧键反序列化缺字段默认 null；原生键始终 null。估算的输出范围为 `visibleBody`，不得冒用 includesReasoning。
- T05：`SpeedMetrics` 增 `tokenizerEstimate: SpeedRate`、`bodyObservedMs: number|null`、`shortWindowCount: number`、`smallSampleCount: number`；`SpeedCapabilities` 增 `tokenizerEstimate:boolean` 与 `tokenizerEstimateReason:string|null`。来源增加独立 `estimateState`（supported/enabled/observing/reason/lastRecordAt）；估算停采不能覆盖 Codex 原响应来源状态。
- T05：新增 `tps_tokenizer_estimate_set_enabled(enabled: bool)` 及采集详情返回参考配置身份；沿用 `tps_speed_dashboard(query)` 查询，三个模式使用同一快照时刻。所有新枚举和字段双端、mock、查询键同步。
