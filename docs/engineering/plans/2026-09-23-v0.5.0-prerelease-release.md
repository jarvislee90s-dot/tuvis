## T0 · 分支拓扑核对与工作区收束

做法：fetch origin → 用 is-ancestor/merge-base 核实本地与 fec59a7、与 origin/main 的真实关系；缺 fec59a7 则 merge `origin/feat/phase2-injection`；若基于陈旧 main 分叉则 merge `origin/main` 一次收拢。检视 3 个脏文件：若为 #80 修复完成态 → 跑相关测试后单独提交（关 #80）；半成品则补完或 stash 留证。

## T5 · 提交 PR + 单轮合并审查 + 直接合并

push 分支 → `gh pr create`（正文含矩阵+门禁证据）→ 派 1 个 review 子代理（规格+质量一轮，即本步验收）→ 阻塞则修复复审；可合并 → `gh pr merge --merge`（不等 CI）。

**验收标准**：审查结论零阻塞；PR 已以 merge commit 合入，main 含分支全部提交。
