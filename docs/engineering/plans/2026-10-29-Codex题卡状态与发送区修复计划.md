### 跨任务契约

- T02：`ThreadProjection.projectionVersion` 为可选增量对象，含 `instanceId: string`、`ownerEpoch: number`、`ownerGeneration: number`、`revision: number | null`、`localSeq: number`；Rust 用对应 snake_case 标识并序列化 camelCase。`instanceId` 绑定本次服务／hub 世系，不是每次 GET 随机值。复用已有 boot 身份，不生成第二套身份系统。
- T02：新增 `shouldApplyProjection(current: ThreadProjection | null, incoming: ThreadProjection, context: ProjectionApplyContext): boolean`，导出于 `codex-projection-order.ts`。`ProjectionApplyContext` 字段为 `sessionId: string`、`subscriptionGeneration: number`、`responseSubscriptionGeneration: number`、`allowInstanceChange: boolean`；后者仅在当前代际最新握手确认新 instance 时为 true，旧 GET 无权主动切回旧 instance。服务端版本不明确时不能通过新写资格；原有只读和旧载荷行为维持兼容。
- T03：`OperationStatus.support` 增加 `supported | identifying | unmatched | not_implemented`；现有 `allowed/evidence/reasonCode` 保留语义。新增 `EffectiveOperations.capabilityIdentity: string | null`，为完整目标指纹、包 SHA、规则版本的无路径身份摘要，仅用于区分展示目标。
- T03：`ThreadProjection.activeTurnId: string | null` 来自新鲜镜像同次观察；未知／stale 为 null。它是按钮目标，不替代后端 writer 校验。
- T05：`useCodexTurnControl` 接收当前投影与 sessionId，输出 `canStop/stopping/result/stop`；`stop()` 冻结 turnId，调用既有 `interruptCodexTurn`。真实签名以现有 API 扩展为准，不能省略目标绑定和归属保护。
- T06：若已有 API 无法对 queued 动作定向复用授权，新增 `POST /codex/queue/prioritize`，请求 `{sessionId, actionId, expectedTurnId?, confirmInterrupt, frontBudgetMs?}`，响应判别联合 `prioritized | already_dispatched | not_sent | unknown`，携带原 actionId 与既有动作回执；不接受正文副本。执行者可选择内部函数拆分，但不得改变这些行为。

  由真实 peer 统计目标消息 start-turn 帧，DAO 查询原队列：

  ```rust

  assert_eq!(q1_start_turn_frames + q2_start_turn_frames, 0);

  ```

  停止帧与消息帧分别计数，成功闭环通常是一次 interrupt 和一次 Q3 start-turn，不能混称“总共一帧”。

- [ ] 写安全反例：停止 Unknown／目标换代／原生 pending／未解 Unknown 屏障／过预算／设备失效→不派 Q3；明确 NotSent 不误删其他暂停 token。
- [ ] 复用现有前置暂停、turn 终态确认、queued→reserved CAS 与绑定该 action 的一次性 grant；如需新入口按跨任务契约新增。停止后等待耗时受统一预算约束，前台超时只回 Unknown，不在后台偷偷重发。
- [ ] 前端仅在实际入队反馈中展示“先处理这条”；active 时先简短确认停止该回合，暂停空闲时仅确认本条越队；按钮回执关联原动作，不清除其他消息。不能泛化为普通 FIFO 任意拖动排序。
- [ ] 跑 `cargo test --test codex_ipc_remote`、`cargo test --test codex_control_remote`，及 queue/composer 对应组件测试；提交。

**验收：** 用户明确优先处理具体消息后最多发送一次，旧队列不自动解冻。若实现发现与宪法 FIFO 边界有无法在“已裁决暂停越队”内解决的冲突，停止该新增入口并报告具体冲突，不自行扩大授权或修改宪法；其他任务继续。
