Tunnel Token 使用教程（点击展开/收起） 前置：需要一个托管在 Cloudflare 的域名（免费计划即可）
  1. 登录 dash.cloudflare.com，左侧菜单进入 Zero Trust（首次使用需起个团队名，选 Free 计划）；
  2. 左侧 Networks → Tunnels，点 Create a tunnel，连接类型选 Cloudflared；
  3. 给隧道起个名字（如 mam-jarvis）→ Save tunnel；
  4. 安装方式页不用装任何东西——复制页面里那串 eyJh... 开头的 Token；
  5. 切到 Public Hostname 标签：子域填 mam、域名选你的域名、Service 填 HTTP://localhost:9420 → Save；
  6. 回到 MAM 本页，把 Token 粘贴进输入框点「保存」，状态变「运行中」即完成。
之后地址永久不变；MAM 会自动下载 cloudflared 并守护进程，无需手动安装。

  • 1登录状态常驻：绑定后 180 天滑动有效；切换通道开关 / 改设置 / 重启 MAM 都不掉线。只有显性关闭「开启远程接入」或重置密码才需重新绑定。同一浏览器同一网络重复绑定只覆盖原设备记录，不再 1 刷新 = 1 新设备。

  • 3四通道二维码：二维码 = 通道地址 + 密码参数，扫码自动填入直接进入。

三、隧道生命周期 开关即卡关

每个通道独立开关 = 唯一启停入口。开 = 常驻运行（断线自动重连；切设置页 / 开关其它通道 / 改本机名一律不影响）；关 = 显性停止。临时隧道每次开关都会换新地址（Cloudflare quick tunnel 机制，卡片已明示）；自有域名 / 外部域名地址固定。「开启远程接入」总开关关闭时全部通道联动停止，重新打开时按各卡开关状态自动恢复。
