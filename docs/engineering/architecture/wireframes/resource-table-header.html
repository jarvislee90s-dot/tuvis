交互与边界说明

1. 排序三态：默认（当前扫描序，图标 ⇅）→ 升序（↑）→ 降序（↓）→ 默认。Skill / MCP / 插件各自独立记忆；搜索过滤后仍保持当前排序。
2. 目录按钮：成功后 toast 显示打开的路径；目录不存在自动创建。
3. MCP 文件按钮：用系统默认程序打开配置文件；文件不存在 → toast 报错「MCP 配置文件尚未创建：{路径}」（先在仓库添加后由启用动作生成）。
4. 插件目录：与启用插件的 symlink 目标目录同源（adapter.plugin_dirs），不是 ~/.tuvis/plugins 仓库。
5. 表头仅在该资源列表非空时显示；"全部启用"占位保证右侧列头与行内按钮列对齐。
