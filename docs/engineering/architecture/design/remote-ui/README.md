# 远程端 UI 参考稿（Remote UI Reference）

> **本文件夹是远程端（`src/mobile/`）UI 的唯一视觉权威**。实现阶段所有组件改动必须对照本文件夹内的定稿线稿与 [../tool-color-ledger.md](../tool-color-ledger.md)（配色台账）执行，不得凭记忆或临时发挥，防止风格偏移。
>
> 冲突处置：实现与参考稿冲突 → 以参考稿为准；参考稿确有缺陷 → 先改参考稿（本文件夹 + 台账留痕）再改码，两端不得各自演化。

## 文件约定

- 命名：`NN-<页面>-<主题>.html`（NN 为两位序号，按定稿顺序递增），如 `01-board-看板定稿.html`。
- 形式：**自包含单文件 HTML**（内联全部 CSS，无外部依赖），浏览器直接打开即可看到 1:1 线稿。
- 状态：文件头注释标注「已定稿 / 草案」；只有「已定稿」文件可作为实现依据。
- 每份线稿须覆盖该页面的全部关键状态（空态 / 加载 / 主要交互组件），实现侧按线稿状态逐一对照。

## 权威链

1. `docs/MASTER-PLAN.md`（项目宪法）
2. `docs/engineering/architecture/design/tool-color-ledger.md`（工具配色台账 + 撞色规则 + 字体档位）
3. 本文件夹定稿线稿（逐页面 1:1 视觉基准）
4. spec：`docs/engineering/specs/<日期>-remote-ui-redesign-design.md`（结构 / 行为 / 验收口径）
