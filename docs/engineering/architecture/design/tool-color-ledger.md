# 工具品牌配色台账（Tool Color Ledger）

> **用途**：兔维斯 全端（桌面看板 / 移动远程看板）工具**识别檐色**与撞色规则的唯一权威表。新增工具、修改工具配色、新增彩色 UI 元素前，必须先对照本表检查色相冲突与辨识度。
> **来源**：2026-10-05 远程端 UI 改版头脑风暴（用户逐项裁决 + 官方品牌调研）。
> **实现落点（2026-10-14 统一批起）**：图标 canonical 出处 = `src/components/icons/BrandIcons.tsx`（8 枚 canonical SVG：opencode/zcode/dsh/workbuddy/openclaw 固定品牌色且深色标自带细白边，claude/codex/kimi 为 currentColor）；配色/名字唯一表 = `src/lib/agentBadge.tsx`（`AGENT_BADGE`，含 `brandHex` 裸色）；资源/预设/设置/移动卡片经 `ToolIcon` 薄委托消费。卡片檐色 = `src/mobile/board-logic.ts` 的 `TOOL_BRAND_COLORS(_DARK)`（本表矩阵沿用；设置页远程外观预览亦查此表）。原 `--tool-*` CSS 变量双板体系已退役。

## 一、撞色规则（新工具入册 / 改色必须依次过这三条）

1. **彩色系独占色相**：橙归 Claude；红黄绿的「淡底 + 深字」小徽标形态保留给状态语义（等待 / 运行 / 完成），工具识别色使用高饱和、大面积形态（图标底、卡片檐），两者靠面积与饱和度区分，色相不得完全重合。
2. **黑白系用「墨阶 + 正负形」区分**：墨阶三档 = 纯黑（ZCode）/ 蓝黑（Kimi）/ 墨灰（OpenCode）；正形 = 深底白图形，反形 = 白底深色图形 + 细描边。
3. **撞色让位优先级**：用户点名 > 官方品牌唯一性 > 现状资产。让位方在本表「变更记录」留痕并注明原因。

## 四、夜间皮肤处理规则（2026-10-05 外观系统定案）

夜间皮肤（暖黑 / 纯黑 / 深青）下额外生效三条规则：

1. **黑系工具檐色夜间提亮**（与深底融化，提亮为灰阶）：kimi `#0B0E1A → #8A94A6`（蓝灰）、zcode `#141413 → #A39C8C`（暖灰）、opencode `#6B6B6B → #8C8C88`（中灰）；彩色系檐色（橙/绿/猩红/蓝等）夜间不变。同步地，黑系工具图标在夜间按既有机制处理：kimi 反白（浅底深月牙）、zcode 白色亮描边、codex 反转为深底白符。
2. **卡片亮边**：夜间皮肤卡片边框一律用亮色与底分离——暖黑 `#6E5836`、纯黑 `#4D4D4D`、深青 `#3B6353`；白色系三皮肤维持原细边框不变。（2026-10-05 真机反馈修订：初版 `#55432A/#3A3A3A/#2C4A3E` 与卡底仍过于接近，整体再提亮一档；卡底/气泡/弱文字同步提亮——暖黑 cbg `#3A2C1A`·bub `#564427`·mut `#B0A896`、纯黑 cbg `#1C1C1C`·bub `#2E2E2E`·mut `#9A9A9A`、深青 cbg `#173229`·bub `#24453A`·mut `#8AA39A`。）
3. **主按钮夜间反白**：深底上近黑按钮会隐形，夜间主按钮（发送 / 允许 / 保存）自动反转为亮底深字——暖黑 `#EFE9DC`（字 `#241B0E`）、纯黑 `#F5F5F5`（字 `#111111`）、深青 `#DDEBE3`（字 `#0C1A14`）。

## 五、字体气质档位（同批裁决，随 UI 改版落地）

四档全部使用系统字体栈，零包体成本；设置页「字体气质」单选，默认标准。Android 等无对应系统字体的平台自动回落标准档（已知限制，如实申报）。

**双层字体制度（2026-10-05 用户问询后定案）**：字体档位只切换 **UI 字体**（标题/正文/按钮）；**内容字体恒为系统等宽**（`--font-mono`：代码块、命令、文件路径、时间戳、PIN），任何档位下不跟随切换。理由：代码与路径是需要逐字符辨读的内容（l/1、O/0、参数对齐），且各家 harness 桌面端均为「UI 无衬线 + 代码等宽」的双层惯例。终端档的等宽只作用于 UI 文本的拉丁/数字，不与内容字体冲突。

| 档位 | 中文 | 西文 / 数字 | 气质 |
|------|------|-------------|------|
| 标准（默认） | 苹方 PingFang SC | 系统无衬线（SF Pro） | 与各家桌面 harness 一致 |
| 终端 | 苹方（CJK 无等宽，自动回落） | 系统等宽（SF Mono / Menlo） | 工具感、硬核 |
| 圆润 | 圆体（Yuanti SC） | 系统圆体（ui-rounded） | 轻快、亲和 |
| 书卷 | 宋体（Songti SC） | 衬线（ui-serif / New York） | 人文、编辑感 |
