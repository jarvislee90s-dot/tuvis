[总体台账](../specs/2026-11-25-Codex-Desktop连接诊断与能力边界.md#6-完成台账)只引用与各操作相符的证据。本记录将工程实证、用户手测和待补关口分别记录。早期 TDD 过程、未脱敏的现场输出和历史规划不作为当前执行指令。

## macOS 已验的范围

| 场景 | 证据与结果 | 边界 |
| --- | --- | --- |
| 同一个 App 中手动 A→B→A | macOS `27.0.1` arm64、官方 Codex `26.1120.50957`／`30866`，同实例 AX 只读三帧与本地索引六向核对，能区别当前与另一条原线程 | 未连续采到切换中间态，不是手机主动定位 |
| 隔离 A→B 导航 | 只对获准 B 行做一次语义操作，随后 current 和标题对 B，原宿主未变，A/B 正式记录未见变化，无填入和提交。Codex 前后采样均非系统前台 | 不代表全程未抢焦点，未证明锁屏或最小化 |
| 隔离填入与提交 | 空输入框结构单独取证，程序填入后读回，未提交时无新回合；后续该文本只提交一次，原测试线程恰新增一个正式用户消息，同回合有回复和终态 | 不代替并发或产品体验 |
| 远程页面当前 A→A | 用户报告从真实 Tuvis 远程页面发给已打开的 A，场景通过，现场界面有送达及回复 | 不用上一次回执推断当前写入资格 |
| 远程页面桌面 A、目标 B | 用户报告不用本机点击，由 Tuvis 切到 B 并发送，场景通过 | 未单独提交两条同版本的原宿主账本、B→A 产品操作或竞态证据。未确认项不代勾 |
| 读取与本地保护 | 工程方确认原 A 新回合在两个落盘来源及鉴权路径可读，用户手测查看已保存内容、本地草稿留存和批准文件预览 | 本地暂存不等于正式投递，落盘读取不等于实时状态 |

macOS 实机结论限当时同一个官方 App 常规启动及隔离候选。现有同文本观察不作为任意并发情形的动作归因，桌面进程间操作没有原子写锁。正式 AX 产品开放仍待 F2.8／D7 的单独裁决。Windows 当前安装版未测，见[交接](codex-desktop-windows-hotfix-handoff.md)。
