## 代表性版本与证据

- Mac 冻结候选 `8cde171d` 的主二进制 SHA-256 为 `ea0af140932c31e77a4cdd63ad99d44605bf857331f1f88ee88722f6416b55ed`。只覆盖该版本的隔离签名、资源和桌面验证。带纯转发与停止的 `7cd1414f` 候选主二进制 SHA-256 为 `36a478335a17d66b38537ab2a142663e08dfc97e993df113a00316e872a1b1c5`，覆盖 arm64、严格签名、隔离回环及移动停止资源。
- DSH Desktop `0.2.2-rc.5` 的两份真实转写曾在同一模型下分别观察到 `low` 和 `max`。这两条历史证据来自各自的 `request/header.data.header.config`。当前值另外从官方投影读取，按 [脱敏字段样例](../evidence/2026-11-22-dsh-followup/n05-model-projection.json) 对账。
- 宿主锁、Mac UDS 和 Windows 管道补探测结论并入 [平台附记](../evidence/dsh-native-rpc/plugin-authoring-notes.md)。原始协议报告仍保持接收时的内容与摘要。

复验顺序。先记录构建、宿主版本、浏览器和隔离数据根。验证同动作只送达一次、运行中停止、整组答题、设置回读及媒体与普通预览。在同一个浏览器验证撤设备、切实例、关远程，观察旧连接和新请求均受撤权。真实手机由用户验收，测试记录保留结果和版本。
