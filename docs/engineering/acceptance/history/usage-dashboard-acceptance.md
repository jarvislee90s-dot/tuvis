## §5 几何常量参照（U-5 / U-10 / E-6 用）

`src/lib/usage/miniBar.ts` 的公式常量（**逻辑 px**，实机窗口尺寸 = 该值 ×scale）：

| 常量 | 值 | 说明 |
|---|---|---|
| `MINI_BAR_ROWS` | 5 | 浮窗行数（恒定，三态与空态都渲染 5 行 ⇒ 窗口不抖） |
| `MINI_LINE_H` | 17.4 | 单行高 |
| `MINI_BAR_PAD` | 16 | 容器上下内边距合计 |
| `miniBarHeight(scale)` = `round((5×17.4+16)×scale)` | 0.75 → **77**；1 → **103**；1.25 → **129** | 浮窗高 |
| `MINI_BAR_MAX_H` / `miniBarMaxHeight(scale)` | 120 → 90 / 120 / 150 | 容器 `maxHeight`（放不下才咬） |
| `MINI_BAR_GAP` / `miniBarGap(scale)` | 6 → **5 / 6 / 8** | 浮窗与卡片的竖直间距；**必须计入窗口高度**（U-5） |
| `FRAME_H`（`petAnimations`） | 208 | 精灵帧高，进 `base = round((50 + FRAME_H + 10)×scale)` ⇒ `base` = 201 / 268 / 335 |
| `MINI_HOVER_MS` / `MINI_GRACE_MS` / `MINI_RESTORE_MS` | 500 / **200** / **500** | 悬停出窗 / 移开宽限 / 拖动后恢复 |
| 窗口宽度 | `px(340)` | 恒 340×scale，三档都不加宽 |

U-5 的算式：`窗口高 = ceil(base + 卡片实测高 + miniBarGap(scale) + miniBarHeight(scale))`。
1.25 档下：`base = round((50+208+10)×1.25) = 335`，若卡片实测高为 `H`，则期望
`ceil(335 + H + 8 + 129) = H + 472`（**这个 8 就是 6px 间距 ×1.25**；少了它，浮窗顶边会被窗口上沿裁掉）。
