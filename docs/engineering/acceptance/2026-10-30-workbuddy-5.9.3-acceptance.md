## 3. 代码审查红线（发现即不通过）

- [ ] R2 使用 `MAX(last_activity_at, updated_at)`，没有 `COALESCE`。
- [ ] `runtime_present = 心跳文件存在 ∧ 内容 pid 存活 ∧ sessionId 匹配`；`status='working'` 时不因父会话静默下板。
- [ ] `get_workbuddy_sessions` **删除了** `!heartbeat_is_alive(...)` 的 90s 过滤（保留 UUID/kind/pid）。
- [ ] 心跳候选按 sessionId **合并 DB 行**，状态上拉对心跳候选生效。
- [ ] `get_workbuddy_sessions(&[])` 在任何 `recent_db_sessions` 之前 return 空（L1 契约测试绿）。
- [ ] `find_processes` 对过期心跳不再要求新鲜；只要求 UUID/kind/pid 一致且 pid 存活。
- [ ] 补偿 `is_live` 包含 `runtime_present`；不会把运行中的会话补成未读。
- [ ] 正常完成（心跳文件被 unregister 删除）且 status 非 `working` → 立即补一次；文件残留但过期 → 300s 后才补。
- [ ] 子代理入账：独立游标、`is_subagent=1`、`parent_session_id`、`cwd` 归属正确；主会话数值不变。
- [ ] 没有读取/叠加父 jsonl 的 `providerData.toolResult.subAgent.descriptor.usage`（会双计）。
- [ ] 没有把 `usage_detail` / `usage_daily` 的 rescan 描述为“幂等”；回滚步骤会显式处理 daily。
- [ ] 影子账本路径是 `$TUVIS_HOME/.tuvis/tuvis.db`，不是 `$TUVIS_HOME/tuvis.db`。
- [ ] `deleted_at` 条件接受 cloud 的 `-1` 哨兵（`IS NULL OR <= 0`）。
- [ ] **已删 DB 行 + 残留心跳文件** → 不出卡（`deleted_db_session_with_heartbeat_is_not_shown`）。
- [ ] **已删会话 + 未读池已有行** → 合并前过滤/删除，最终看板无卡（`deleted_workbuddy_pool_rows_are_not_merged_to_cards`）。
- [ ] **已删会话 + LAST_SEEN 残留** → 心跳消失后补偿不生成未读（`deleted_session_with_stale_last_seen_is_not_compensated`）。
- [ ] **DB 不可读 ≠ 删除**：`deleted_workbuddy_session_ids` 返回 `None`，不得清理未读池/观测。
- [ ] **DB-only completed → 未读 → `mark_session_read` → 下一轮扫描无卡**；墓碑后新工作回合恢复出卡（`read_completed_db_only_card_is_dropped_until_new_activity`）。
- [ ] **completed + 残留心跳 + pid 存活 + DB/jsonl 超 300s**：看板下板且补偿恰好一次（`completed_stale_heartbeat_with_live_pid_is_compensated`）。
- [ ] **working + 心跳文件消失 + DB/jsonl 超 300s + 尾部 Idle**：补偿不得插未读（`working_missing_heartbeat_is_not_compensated`）。
- [ ] **mtime 不可得不等于刚刚活跃**：completed + DB 超窗 + mtime=None 不 live（`live_requires_known_mtime_for_completed`）。
- [ ] **JSONL 暂缺时保留 LAST_SEEN**，文件出现后下一轮补一次（`missing_jsonl_keeps_observation_for_retry`）。
- [ ] **JSONL 路径存在但读取失败**（目录/权限/IO）→ 保留观测，不把空数组当非完成态消费（`missing_jsonl_keeps_observation_for_retry` 的目录分支）。
- [ ] **补偿落库成功后才消费观测**：`unread::try_upsert` 失败保留 LAST_SEEN 下轮重试；成功后移除（代码审查项）。
- [ ] **512KB 尾部窗口起点落在多字节 UTF-8 中间**：合法长 JSONL 仍读出最后完成行（`tail_reader_tolerates_utf8_boundary`）。
- [ ] **普通首次转绿写库失败**：`RefreshDisplay` + 池行不存在 + 无已读墓碑 → 下一轮补插；有墓碑不复活（代码审查项）。
- [ ] **数据驱动绿卡首次 INSERT 失败**：待重试标记让预过滤保留卡片，下一轮真正进入补插；本次转绿后的已读墓碑才取消，旧回合墓碑不阻止（`pending_unread_retry_keeps_green_card_through_prefilter`）。
- [ ] **待重试期间状态缓存不得提前写 Idle**：重启后仍走首次 Insert 重试（代码审查项）。
- [ ] **首次写库失败 + 用户已读**：本回合墓碑（`read_at >= 本次活动`）取消重试；旧回合墓碑不影响（`insert_should_skip_for_read` 分支）。
- [ ] **上述场景重启后**：无内存标记时用卡片活动时间兜底，本回合已读不得重插。
- [ ] **状态缓存失忆 + 旧墓碑 + 新回合活动**：允许插入；墓碑覆盖活动或无活动 → 不插（`unread_insert_allowed`）。
- [ ] **Codex 秒级活动与毫秒墓碑同秒**：不判为本回合已读；毫秒级活动照常严格比较（`read_covers_activity`/`activity_may_be_after`）。
- [ ] **待重试标记跨重启**：独立文件 `~/.tuvis/unread_pending_retries.json` 恢复 `since`；同秒已读在重启后仍按精确 `since` 拦截（`insert_should_skip_for_read(Some(since), read_at, activity)`）。
- [ ] **写放大与 TTL**：`mark/clear` 仅实际变化时落盘；每轮清理 >24h 内存项；文件写失败只降级并记日志。
- [ ] **Windows 替换安全**：Unix 原子 rename；Windows 优先 `ReplaceFileW`（目标不存在时 `MoveFileExW`），失败时先保留旧文件为 `.bak` 再换入，换入失败恢复旧文件；主文件缺失/损坏时加载回退 `.bak`，不出现“先删旧、后失败”的空窗（`pending_retry_file_roundtrip_and_backup_fallback`、`pending_retry_persist_failure_preserves_primary_snapshot`、`pending_retry_second_rename_failure_restores_primary`）。
- [ ] **主文件损坏 + 备份有效**：不得删除/覆盖唯一有效 `.bak`；换入失败仍可从备份恢复；换入成功后可清理备份（`pending_retry_corrupt_primary_keeps_valid_backup_on_failure`、`pending_retry_corrupt_primary_replaced_from_valid_tmp`）。
- [ ] **加载失败可重试**：临时 I/O/解析失败不置位已加载，下一轮扫描继续；文件确实不存在才视为完成（`pending_retry_load_retries_after_transient_failure`、`pending_retry_load_absent_marks_loaded`）。
- [ ] **不可读快照不得被原子替换覆盖**：加载完成前禁止落盘；`persist_pending_map` 在写 tmp/替换前检查主文件（损坏/缺失时连同 `.bak`），`IoError` 直接跳过并保留旧文件；恢复后合并内存新增项与磁盘旧项再补写（`pending_retry_persist_gate_waits_for_load_and_merges`、`pending_retry_persist_blocks_when_primary_unreadable_and_merges_after_restore`、`pending_retry_persist_does_not_overwrite_unreadable_primary`）。
- [ ] **无待重试标记时的秒级同秒歧义**：明确接受“宁可允许通知”的取舍；毫秒级来源严格比较。
- [ ] **P2-3 已接受**：JSONL 长期缺失时观测 TTL 会被重试刷新；作为已知限制记录，后续加 first-seen 上限。
- [ ] **只 touch mtime 不复活已读完成卡；同秒/毫秒级新工作可恢复**（`db_only_completed_last_activity_ignores_mtime_touch`、`read_completed_db_only_card_is_dropped_until_new_activity`）。
- [ ] **首次模型出现在工具回执行**：call 先 start、回执后 finish，`tool_calls=1` 且 `tool_ms` 不为 0（`first_model_on_tool_result_replays_call_before_finishing`）。
- [ ] **已有游标的截断/重写拒绝入账**：首读/回填照常；重扫返回 `usage-source-io`，detail 指向按文件专用重建，旧账本/游标不被覆盖（`truncated_rewrite_with_cursor_is_refused_without_ledger_write`、`subagent_rescan_with_cursor_is_refused`）。
- [ ] **新工作判据只认业务条目**：用户消息/模型请求/工具执行推进时间；`credit-usage`、`ai-title`、`file-history-snapshot` 等辅助记录不推进（`new_work_timestamp_ignores_auxiliary_records`）。
- [ ] **补偿按已读时间 vs 最后新工作判定**：Idle 缓存不单独阻断；已读覆盖最后新工作才跳过，已读后新回合允许补一次（`compensation_uses_read_time_against_last_work`、`status_cache_idle_alone_does_not_block_compensation`）。
- [ ] **跨重启恢复链路（模拟）**：真实 SQLite 首次 INSERT 失败 → pending 落盘 → 新连接/建表/恢复标记 → 补插成功；失败后已读墓碑覆盖 since 时不复活（`pending_retry_restart_after_real_insert_failure`）。
- [ ] **未读通知使用独立转绿时间**：业务活动十分钟前、转绿现在 → 通知一次；转绿超过 2 分钟 → 静默；已读后无新业务不复活（`unread_turned_green_at_ms` / `unreadTurnedGreenAtMs`；`pending_retry...` 看板断言 + `firstSeenUnread.test.ts`）。
- [ ] **文件定位失败不得伪装没用量**：主目录/兜底目录权限失败 → `usage-source-io`；正常缺失 → 跳过；权限恢复后继续采集（`find_session_jsonl_strict`；`strict_finder_propagates_unreadable_primary_directory`、`strict_finder_propagates_unreadable_fallback_directory`、`unreadable_project_dir_fails_then_recovers`）。
- [ ] **子代理最终身份统一校验**：stem 等于父/其他主会话 id → 命名空间 `workbuddy-subagent:<file_key>`；不同目录同名降级文件不串号；旧缓存冲突 → 报错不静默换 ID（`subagent_stem_equal_to_parent_is_namespaced`、`same_stem_in_different_dirs_gets_distinct_ids`、`cached_conflicting_subagent_identity_is_refused`）。
- [ ] **已删除历史主会话仍保留身份**：冲突集合来自不带 `deleted` 过滤的全部 DB 主会话；行内引用已删 B → 降级命名空间，缓存引用 → 报错（`deleted_main_session_is_still_reserved_for_identity`、`cached_deleted_main_session_is_refused`）。
- [ ] **符号链接项目目录**：mangle 未命中时严格查找跟随 symlink 目录，父文件与子代理均能采集（`strict_finder_follows_symlinked_project_dir`、`symlinked_project_dir_collects_parent_and_subagents`）。
- [ ] **子代理目录条目/`file_type()` 非 NotFound 失败** → 整源 `usage-source-io`，不得静默跳过文件。
- [ ] **DB-only completed 卡 + 未读池行** → active 卡标 `unread=true`，不出现“普通卡吞未读”（`workbuddy_db_only_idle_card_with_pool_is_marked_unread`）。
- [ ] 子代理身份解析不等于任何 DB 主会话 id（不只父 id）；降级使用 `workbuddy-subagent:<file_key>` 且有 warn；缓存冲突直接报错。
