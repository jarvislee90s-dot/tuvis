## 3. 代码审查红线（发现即不通过）

- [ ] R2 使用 `MAX(last_activity_at, updated_at)`，没有 `COALESCE`。
- [ ] `runtime_present = 心跳文件存在 ∧ 内容 pid 存活 ∧ sessionId 匹配`；`status='working'` 时不因父会话静默下板。
- [ ] `get_workbuddy_sessions` **删除了** `!heartbeat_is_alive(...)` 的 90s 过滤（保留 UUID/kind/pid）。
- [ ] 心跳候选按 sessionId **合并 DB 行**，状态上拉对心跳候选生效。
- [ ] `get_workbuddy_sessions(&[])` 在任何 `recent_db_sessions` 之前 return 空（L1 契约测试绿）。
- [ ] `find_processes` 对过期心跳不再要求新鲜；只要求 UUID/kind/pid 一致且 pid 存活。
- [ ] 补偿 `is_live` 包含 `runtime_present`；不会把运行中的会话补成未读。
- [ ] 正常完成（心跳文件被 unregister 删除）且 status 非 `working` → 立即补一次；文件残留但过期 → 300s 后才补。
- [ ] 子代理入账：独立游标、`is_subagent=1`、`parent_session_id`、`cwd` 归属正确；主会话数值不变。
- [ ] 没有读取/叠加父 jsonl 的 `providerData.toolResult.subAgent.descriptor.usage`（会双计）。
- [ ] 没有把 `usage_detail` / `usage_daily` 的 rescan 描述为“幂等”；回滚步骤会显式处理 daily。
- [ ] 影子账本路径是 `$TUVIS_HOME/.tuvis/tuvis.db`，不是 `$TUVIS_HOME/tuvis.db`。
- [ ] `deleted_at` 条件接受 cloud 的 `-1` 哨兵（`IS NULL OR <= 0`）。
- [ ] **已删 DB 行 + 残留心跳文件** → 不出卡（`deleted_db_session_with_heartbeat_is_not_shown`）。
- [ ] **已删会话 + 未读池已有行** → 合并前过滤/删除，最终看板无卡（`deleted_workbuddy_pool_rows_are_not_merged_to_cards`）。
- [ ] **已删会话 + LAST_SEEN 残留** → 心跳消失后补偿不生成未读（`deleted_session_with_stale_last_seen_is_not_compensated`）。
- [ ] **DB 不可读 ≠ 删除**：`deleted_workbuddy_session_ids` 返回 `None`，不得清理未读池/观测。
- [ ] **DB-only completed → 未读 → `mark_session_read` → 下一轮扫描无卡**；墓碑后新工作回合恢复出卡（`read_completed_db_only_card_is_dropped_until_new_activity`）。
- [ ] **只 touch mtime 不复活已读完成卡；同秒/毫秒级新工作可恢复**（`db_only_completed_last_activity_ignores_mtime_touch`、`read_completed_db_only_card_is_dropped_until_new_activity`）。
- [ ] **首次模型出现在工具回执行**：call 先 start、回执后 finish，`tool_calls=1` 且 `tool_ms` 不为 0（`first_model_on_tool_result_replays_call_before_finishing`）。
- [ ] **子代理目录条目/`file_type()` 非 NotFound 失败** → 整源 `usage-source-io`，不得静默跳过文件。
- [ ] **DB-only completed 卡 + 未读池行** → active 卡标 `unread=true`，不出现“普通卡吞未读”（`workbuddy_db_only_idle_card_with_pool_is_marked_unread`）。
- [ ] 子代理身份解析不等于任何 DB 主会话 id（不只父 id）；文件 stem 兜底有 warn。
