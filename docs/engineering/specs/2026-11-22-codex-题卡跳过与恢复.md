# Codex 题卡跳过与恢复

## 产品行为

- **异步单题组**可在 Tuvis 跳过。展示决定按完整题组和内容代次持久保存，并同步到已配对的远程端。选择「仅 Tuvis」时只收起远程展示。
- **原生关闭**需要明确配对、受支持的 Windows 包、同一线程与题组，以及原生面板实际只有一道题。调用前重新核对窗口、卡片、来源与操作资格。跳过最多触发一次目标卡片的关闭动作，不提交答案或草稿，不停止当前回合。
- **恢复**只恢复 Tuvis 的展示决定。当前来源已经消失时，可以恢复历史记录的决定，页面不生成待答卡，桌面卡也不重开。异步多题组继续使用原有收纳。
- **即时题卡**的「跳过（仅 Tuvis）」收起当前标签页中的整张请求卡。页面内恢复保留原题与草稿，刷新后只保留收起标记。真实待答状态与普通发送限制继续有效。

## 事实与安全边界

- 题组身份由服务器的 `threadId`、`sourceTurnId`、`sourceItemId` 与 `contentGeneration` 决定。来源不完整、面板不合格或已换代时，不能借客户端状态获得原生操作资格。
- 展示决定与原生结果独立保存。只有同上下文且有合格连续性证据时，程序才报告已核证关闭。当前真实 Windows 可能只能报告未确认，即使用户观察到卡片已消失。
- 同一个动作的重试重用原动作 ID 和请求。对已持久完成的请求重放原回执。失联、超时或恢复运行不自动再次执行原生动作。
- 原生执行与发送控制共用线程锁。HTTP 客户端退出后仍保持已承接作业的责任，直至原生静止和结果持久化得到确认。

## 验收边界

用合成 Desktop peer、临时 SQLite 和测试 provider 覆盖无绑定零原生调用、健康绑定恰一次调用、已承接断连结算、跨端同步、恢复与换代隔离。Windows 实机复验须分别记录 Tuvis 展示、用户观察和机器报告。受支持的原生关闭包为 `OpenAI.Codex_26.1106.6628.0_x64__2p2nqsd0c76g0`，包版本相符后仍须通过实际资格检查。
