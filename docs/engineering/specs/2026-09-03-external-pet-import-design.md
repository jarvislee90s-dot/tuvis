# 外部宠物导入机制设计（codex 宠物迁移）

> 状态：待用户审阅 · 2026-09-03
> 前置文档：`2026-09-01-foxbell-pet-design.md`（内置 foxbell 桌宠，本设计不改变其行为）

## 1. 背景与目标

当前宠物 foxbell 的素材打包在程序内部（`public/pet/`）。本项目宠物系统本身移植自 codex pet，而 codex 生态已有大量现成宠物素材（本地 `~/.codex/pets/`、在线画廊 petdex.dev，全库 4674 只）。本设计新增**外部宠物导入机制**：

- 宠物仓库落位 `~/.mam/pets/`，支持从 codex 目录、本地文件夹/压缩包、petdex 在线链接三种渠道导入；
- 支持直接把合规素材文件夹放进 `~/.mam/pets/`（文件夹直投）；
- 设置页可选择激活 foxbell（内置）或任一已导入宠物；
- 可选导入语音与字幕（字幕 = 音频文件名），并对素材完备性做校验与能力门控。

**不参与**宠物生成环节（hatch-pet 流程），只做素材迁移。

## 2. 决策记录（已与用户确认）

| # | 决策 |
|---|------|
| EP1 | 支持 v1（8×9 行）与 v2（8×11 行）图集；v1 优雅降级——常规 9 行动作照常播放，仅无"空闲 6 秒环视"动画。依据：petdex 全库 97.6% 为 v1，本地 codex 宠物 9/11 为 v1，测试素材 starry-dew 为 v1 |
| EP2 | 启动时发现激活宠物素材异常 → **主窗口弹窗确认**（而非静默降级），宠物窗口自身永不弹窗 |
| EP3 | "修改宠物"范围 = 音频增删改 + 字幕开关 + **删除宠物** + **重命名宠物**（后两项为补充确认） |
| EP4 | 架构采用**混合分工**：Rust 负责 IO/网络/zip/manifest 写入（新增 `services/pet/`，对齐 `services/resource` 模式），前端负责媒体探测（音频时长、图集尺寸）、校验交互与渲染；外部素材经 Tauri asset 协议加载 |
| EP5 | 激活期间宠物文件夹视为**运行时冻结**：UI 不编辑激活中宠物的素材（修改/删除/重命名前自动切回 foxbell）；唯一例外是用户明确确认的修复性 manifest 更新。不做 OS 级写保护（codex 也无任何保护，纯静态文件）。修订（2026-09-04）：编辑保存/重命名完成后自动切回原宠物（经 foxbell 闪切 + 热重载实现）；删除仍回退 foxbell。 |
| EP6 | 激活时音频**全量读入内存生成运行时快照**，运行期不受磁盘变动影响；不按文件夹大小分档（双路径复杂度不值），仅 >30MB 软性警告 |
| EP7 | 切换校验统一为一条路径（直投与 UI 导入相同）：稳态（素材无变动）纯 stat 比对 **<100ms**；全量重探（素材大改/首激活）**<1s** |
| EP8 | 字幕文本 = 音频文件名（去扩展名），与 foxbell 现有 manifest 行为一致；是否启用字幕在导入时选择 |
| EP9 | 向导与设置页所有非直观概念处提供**悬浮提示（tooltip）**（如"字幕 = 音频文件名"、四分组含义、v1 无环视等） |
| EP10 | foxbell 内置行为零改动，仅作为宠物列表中的"内置"选项出现 |

## 3. 术语与素材规格

| 术语 | 含义 |
|------|------|
| v1 图集 | `spritesheet.webp` 尺寸 1536×1872（8 列 × 9 行，帧 192×208），无 look 环视行 |
| v2 图集 | `spritesheet.webp` 尺寸 1536×2288（8 列 × 11 行），第 10-11 行为 16 帧环视 |
| codex 宠物 | `~/.codex/pets/<id>/` 下的 `pet.json` + `spritesheet.webp`；pet.json 含 id/displayName/description/spriteVersionNumber |
| petdex | 在线宠物画廊 petdex.dev。清单接口 `GET /api/manifest` 返回全量宠物列表（slug/displayName/zipUrl/spriteVersionNumber 等字段）；每个宠物的 `zipUrl` 指向 `pet.json + spritesheet.webp` 结构的压缩包 |
| 宠物 ID | `~/.mam/pets/` 下的文件夹名。foxbell 为保留 ID |
| 文件夹直投 | 用户不经 UI，直接把素材文件夹放入 `~/.mam/pets/` |

**动作行映射**：codex v1/v2 的 9 个标准动作行与 foxbell 图集逐行一致（idle / run-right / run-left / waving / jumping / failed / waiting / running / review），无需映射表；差异仅在 v2 多出的两行环视。

## 4. 宠物仓库与 manifest 规范

### 4.1 目录结构

```
~/.mam/pets/
  <pet-id>/                     # 文件夹名 = 宠物 ID
    spritesheet.webp            # 必需。尺寸必须为 v1 或 v2 规格，其余非法
    manifest.json               # MAM 宠物清单（导入向导写入 / 首次激活扫描生成 / 修复更新）
    manifest.json.bak           # manifest 更新前自动备份，仅保留最近一份
    voice/                      # 可选音频，四个固定分组
      general/  approval/  done/  error/
  .import-staging/<uuid>/       # 导入暂存区；finalize 原子移动，取消即清理
```

- `pet.json` 不导入、不解析（MAM 不强制）；导入 codex/petdex 宠物时仅取 `spritesheet.webp`，展示名从源 pet.json 预填向导。
- foxbell 不占用本仓库，仍走内置 `public/pet/`。

### 4.2 manifest.json 字段

```json
{
  "schemaVersion": 1,
  "id": "starry-dew",
  "displayName": "Starry Dew",
  "description": "（可选）",
  "source": "codex | petdex | folder | zip",
  "spriteVersionNumber": 1,
  "spritesheetSizeBytes": 1652314,
  "hasVoice": true,
  "hasSubtitle": true,
  "voices": [
    { "group": "general", "name": "休息一下吧", "file": "voice/general/休息一下吧.m4a",
      "sizeBytes": 123456, "durationMs": 3200 }
  ]
}
```

| 字段 | 规则 |
|------|------|
| `id` | = 文件夹名 |
| `name`（voices 内） | 字幕文本 = 音频文件名去扩展名 |
| `sizeBytes` / `durationMs` / `spritesheetSizeBytes` | 导入/更新时探测后**缓存**，用于后台快速比对（存在性 + 大小），后台校验不解码媒体 |
| `hasVoice` / `hasSubtitle` | 能力门控唯一依据（右键"声音/字幕"开关能否打开） |
| `spriteVersionNumber` | v1=1 / v2=2；前端 Image 探测尺寸后写入，校验时信任并复核 |

## 5. 素材完备性标准与能力门控

### 5.1 三档标准

| 档位 | 条件 | 解锁能力 |
|------|------|---------|
| 最低档（可激活） | spritesheet.webp 存在且尺寸合法（v1 或 v2） | 显示、全部常规动画（v1 无环视）、拖拽/点击等交互 |
| 语音档 | 最低档 + voice/ 四分组（general/approval/done/error）各至少 1 个**合法音频** | 右键"声音"开关可开 |
| 字幕档 | 语音档 + 该宠物选择了同步导入字幕 | 右键"字幕"开关可开 |

**合法音频**：格式 ∈ {m4a, mp3, wav, ogg, opus, flac, aac}（大小写不敏感）；1s < 时长 < 20s；单文件 ≤ 10MB。

**全有或全无**：任一分组无合法音频 → 整个宠物按无语音处理（不达标文件保留在磁盘、manifest 不收录、校验报告说明原因）。

### 5.2 降级行为

- 无语音宠物：声音开关默认关且不可开（置灰 + tooltip 说明）；任务完成/审批等提示音**回落到主看板系统提示音**（解除宠物声音接管）；字幕开关恒关。
- 切换宠物时提示音接管随能力自动切换：激活有语音宠物 → 宠物接管；激活无语音宠物或 foxbell → 按 foxbell 现有规则恢复。
- v1 宠物：仅缺少空闲环视动画，其余行为与 v2 一致。
- 宠物窗口永不因素材问题崩溃/白屏：渲染前探测失败 → 降级 foxbell 或隐藏。

## 6. 校验需求（统一算法）

**一条路径**：无论 manifest 是否存在、无论导入渠道，切换/启动时执行同一校验流程：

1. **stat 快扫**（Rust，毫秒级）：spritesheet 与全部 voice 文件的存在性 + 大小清单，一次取回。
2. **无 manifest（文件夹直投首激活）**：全量探测（图集尺寸 + 逐音频时长，并行加载元数据）→ 按三档标准判定 → 生成 manifest.json → 激活。直投默认有语音即有字幕。
3. **有 manifest**：逐条比对（存在 + 大小与缓存一致，不解码）→ 全部一致直接激活（时长信任缓存）；不一致（文件增删改）→ 弹窗三选：`根据现有素材更新 manifest（自动备份 .bak）` / `忽略，按磁盘降级运行` / `取消`。修复更新只对**新增/变动文件**重新探测时长。
4. 图集缺失或尺寸非法 → 无法激活/弹窗（见 6.1）。

**性能要求（EP7）**：稳态 <100ms；全量重探 <1s。

### 6.1 启动时校验（EP2）

主窗口启动时若激活的是外部宠物：静默快速校验（stat 比对 + 宠物窗口渲染前图集探测）。发现问题 → 弹窗列出问题清单：

- 一般问题（manifest 不一致、音频缺失）：`更新 manifest（自动备份）` / `切回 foxbell` / `忽略并降级运行`；
- 图集彻底缺失/非法：仅 `切回 foxbell` / `关闭宠物`。

宠物窗口不阻塞、不弹窗，按降级策略先行渲染；主窗口决策经事件同步。

## 7. 运行时语义

- **冻结（EP5）**：对激活中宠物执行修改/删除/重命名 → 先自动切回 foxbell（toast 提示）再执行，完成后不自动切回。例外：6.1/6-3 中用户明确确认的修复性 manifest 更新。
- **内存快照（EP6）**：激活时音频全量读入内存（内存 URL），图集经浏览器加载即驻留；激活后磁盘变动不影响运行行为，差异在下次启动/切换校验时捕获。
- **热切换**：切换宠物不重启宠物窗口，动画与音频无缝换装。

## 8. 导入向导

设置页 → 桌宠栏目新增 **导入宠物 / 修改宠物 / 切换宠物** 三入口。向导 = 选择来源 → 配置确认。

### 8.1 渠道 A：从 codex 导入

- 扫描 `~/.codex/pets/`，列出含 spritesheet.webp 的宠物（文件夹名、展示名、v1/v2 徽标、已导入置灰标记）；单选进入配置。
- 仅复制 `spritesheet.webp`。

### 8.2 渠道 B：本地文件夹 / 压缩包

- 原生系统选择器选一个文件夹或 zip。
- 定位 spritesheet.webp：根目录优先 → 子目录递归一层；文件夹/zip 携带的 `voice/{分组}/` 结构自动带入音频配置。
- zip 兼容一层包裹目录（petdex zip 为根级两文件）。

### 8.3 渠道 C：petdex 在线导入

- 界面提供 [浏览 petdex.dev] 按钮（打开系统浏览器）+ 链接粘贴输入框（如 `https://petdex.dev/pets/capvolt`）。
- 解析链接取 slug → 查询清单接口获取 zipUrl → **仅下载 zip** → 解压取 spritesheet.webp（+ pet.json 预填展示名）。
- 下载仅限 petdex 域名白名单；失败（网络/无效链接/找不到宠物）明确报错，不影响其他功能。

### 8.4 配置确认（三渠道统一）

1. 基本信息：宠物名（= 目标文件夹名，默认来源名，可编辑，非法字符/重名实时校验）、展示名（预填）、描述（可选）。
2. 图集预览：idle 首帧静态预览 + v1/v2 徽标；尺寸非法在此报错阻断。
3. 音频配置（可选）：四分组各自添加文件（多选、按合法格式过滤）；自动带入的 `voice/` 结构可增删；每文件内联校验（时长/大小/格式）标注与原因；**四分组各 ≥1 合法文件才启用语音**，否则按无语音导入（不阻断）；显示语音总大小，>30MB 软性警告。
4. 字幕选项：`同步导入字幕（字幕 = 音频文件名）` 开关，默认开；无音频时禁用。
5. 执行导入：全量校验（同 6-2 路径）→ 落地 `~/.mam/pets/<名字>/` + 写 manifest → 成功页提供 [立即激活]（走 6-3 快路径）与 [完成]。
6. 取消/失败：暂存区清理，无残留。

所有步骤按 EP9 提供 tooltip。

## 9. 切换宠物

- 宠物列表卡片：foxbell（"内置"徽标）+ 已导入宠物（idle 首帧缩略图、名称、v1/v2 徽标、语音/字幕能力徽标、激活高亮）。
- 点击卡片 → 执行第 6 节统一校验 → 通过则激活热切换（toast）；不一致弹窗三选；图集非法阻断并说明。
- 卡片徽标实时反映校验后真实能力（所见即所得）。
- 删除激活中宠物 → 自动先切回 foxbell 再删。

## 10. 修改宠物

- 选择已导入宠物进入管理面板（激活中的也可选，执行修改前按 EP5 自动切回 foxbell）。
- 能力（均带 tooltip）：
  1. **重命名**：改文件夹名（= ID），实时校验；manifest 同步更新。
  2. **展示名/描述**：直接编辑。
  3. **音频增删改**：与 8.4-3 相同的四分组界面；保存时全量重探变动文件，更新 manifest（自动备份）。
  4. **字幕开关**：切换同步导入字幕选项。
- 保存 = 写 manifest.json.bak → manifest.json。
- 与文件夹手动管理兼容：手动改动由下次切换/启动校验捕获。

| 位置 | 变更 |
|------|------|
| 设置页 · 桌宠栏目 | 新增三入口（导入/修改/切换）+ 宠物列表卡片（当前激活展示） |

| i18n | 所有新增文案中英双语 |

## 12. 渲染与资产加载

- 外部宠物的图集与音频经 Tauri asset 协议按绝对路径加载（asset 协议 scope 严格限定 `~/.mam/pets/**`）；manifest 内容经 IPC 读取。
- 渲染引擎按探测到的行数（9 或 11）适配：v1 清空环视帧序列，其余动作行共用现有动画状态机；对现有 foxbell 渲染路径无行为变化。
- 激活指针持久化于宠物配置存储（与现有宠物配置同族、跨窗口同步），宠物窗口与设置页经事件协同热切换。

## 13. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 校验稳态 <100ms、全量 <1s（EP7）；导入下载/解压有进度反馈与超时 |
| 安全 | zip 解压防路径穿越（zip slip）与解压总大小上限；下载域名白名单（仅 petdex 资产域）；文件名合法化；一切外部输入按不可信对待 |
| 内存 | 音频快照 = 文件大小之和（现实 1-5MB 量级）；图集解码位图 ≈14MB 为显示固有成本 |
| 兼容 | Windows/macOS 文件名与路径规则；不改 foxbell 内置行为（EP10） |

## 14. 错误处理原则

- 宠物永不因素材问题崩溃/白屏；音频播放失败静默降级（沿用现有语义）。
- 弹窗只出现在主窗口；宠物窗口先行降级渲染。
- 写操作先备份后写入；暂存区原子落地。
- 网络失败可重试可跳过，只影响当次导入。

## 16. 范围外（YAGNI）

- OS 级文件锁/ACL 写保护（EP5 已论证）
- 宠物生成环节（hatch-pet）
- v1→v2 图集自动补齐
- 音频转码/裁剪（不合规直接排除）
- petdex 内嵌浏览/搜索（仅"浏览器 + 粘贴链接"）
- 多宠物同显

## 17. 技术实现备忘（细节由实施计划决定）
