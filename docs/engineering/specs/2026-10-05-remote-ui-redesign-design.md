# 远程端 UI 改版设计（Remote UI Redesign）

- 日期：2026-10-05
- 状态：已评审通过设计方向，待用户评审本 spec 后转实施计划
- 权威链：`docs/MASTER-PLAN.md`（宪法）→ [`docs/engineering/architecture/design/tool-color-ledger.md`](../architecture/design/tool-color-ledger.md)（配色/字体台账）→ [`docs/engineering/architecture/design/remote-ui/`](../architecture/design/remote-ui/)（定稿线稿）→ 本 spec（结构与行为）

## 1. 背景与目标

远程端（`src/mobile/`，axum 伺服于 `/m` 的手机看板/网页端）当前视觉为临时拼凑：slate 灰底卡对比弱、工具过滤 chips 品牌色实底花杂、状态用裸圆点需记忆、消息气泡浅蓝与白色系冲突、emoji 当图标。用户裁决对其做整体设计语言重定，目标是：

1. **白色系为主**，对齐 Claude / Codex 等 harness 桌面端的扁平质感（细边框分层、克制、近黑主控）；
2. **工具识别度制度化**：8 个工具的品牌色与符号按官方经典配色固化进台账，用户用久可「看色识工具」；
3. **个性化**：皮肤、字体、圆角、品牌点缀四个 DIY 要素在桌面端配置、实时预览、下发生效，移动端不做切换 UI。

**明确不做**（本期）：桌面端换肤（维持现状，Token 命名预留双端共用）；信息密度 / 阴影深度 / 状态徽标形态三个候选轴（二期）；新皮肤扩充机制上线（雾青/深青已入首发）。

## 2. 范围

| 端 | 范围 |
|----|------|
| 远程端 `src/mobile/` | 全页面：看板、会话详情（消息流/审批卡/问答卡/输入区/文件面板）、历史归档、归档详情、配对页；mobile.html 防闪脚本；mobile.css Token 表 |
| 桌面端 `src/`（仅两处） | ① 设置页「外观」节重构为两分区大框（桌面端维持现状内容 + 远程端外观配置器）；② 共享组件 `ToolIcon.tsx` 重绘（桌面端随之更新图标，属台账落地） |
| 后端 `src-tauri/` | 新增远程端外观配置的存取与 `/m/api/v1/ui-config` 下发接口 |

不改动：会话扫描、注入、配对加密等一切非视觉逻辑；桌面端其余页面样式。

## 3. 设计语言

### 3.1 语义 Token（双皮肤 × 6 皮肤）

所有远程端组件禁止硬编码颜色/圆角/字体，一律消费以下 CSS 变量（定义于 `src/mobile/mobile.css`，`:root` 为白天、`.dark` 覆盖为夜间；皮肤切换 = 切换变量表）：

| Token | 语义 |
|-------|------|
| `--pg / --cbg / --cb / --tx / --mut` | 页面底 / 卡片底 / 卡片边 / 主文字 / 弱文字 |
| `--sh` | 卡片阴影（纯色系皮肤为 `none`） |
| `--bub` | 用户消息气泡底 |
| `--btnp / --btnpt` | 主按钮底/字（夜间反白，见台账夜间规则 3） |
| `--rr` | 卡片圆角（用户可配 8/12/18/22px） |
| `--font-ui / --font-mono` | UI 字体（随档位）/ 内容等宽字体（恒定，双层字体制度见台账） |

六张皮肤 Token 表（定稿值，与 04 参考稿 `SKINS` 对象逐字一致）：

| 皮肤 | pg | cbg | cb | tx | mut | sh |
|------|----|-----|----|----|-----|----|
| 暖白纸感（白天默认） | `#F8F3E9` | `#FFFDF8` | `#EAE2CF` | `#2B2417` | `#97907E` | 双层柔影 |
| 极简纯白 | `#FFFFFF` | `#FFFFFF` | `#E3E3E1` | `#141414` | `#8F8F8B` | none |
| 雾青 | `#EFF3F2` | `#FFFFFF` | `#DFE7E5` | `#1D2422` | `#87928F` | 双层柔影 |
| 暖黑纸感（夜间默认） | `#271D0F` | `#352817` | `#55432A` | `#F0E9DC` | `#A79E8C` | 深影 |
| 极简纯黑 | `#0A0A0A` | `#161616` | `#3A3A3A` | `#F5F5F5` | `#8A8A8A` | none |
| 深青 | `#0C201B` | `#12281F` | `#2C4A3E` | `#E8F0EC` | `#7E938C` | 深影 |

夜间皮肤额外生效台账「夜间皮肤处理规则」：黑系檐色提亮表（kimi `#8A94A6` / zcode `#A39C8C` / opencode `#8C8C88`）、卡片亮边（已含于上表 cb）、主按钮反白（`--btnp/--btnpt`，值见台账）。

### 3.2 品牌色与图标（→ 台账，不在此重复）

工具识别色、自制 Logo 处理（含 dsh 鲸鱼、codex 自绘提示符）、撞色三规则、夜间檐色提亮，全部以 [`tool-color-ledger.md`](../architecture/design/tool-color-ledger.md) 为唯一权威。实现侧改动 = `ToolIcon.tsx` 重绘 6 个图标（claude 橙 / codex 黑白绿点缀 / zcode 纯黑 / opencode 反形 / openclaw 猩红 / dsh 鲸鱼）+ `index.css` 与 `mobile.css` 的 `--tool-*-bg/fg` 变量改值，桌面移动一处生效。

### 3.3 组件语汇

- **状态徽标**：红黄绿淡底彩字 pill（等待批准 / 运行中(思考中·压缩中) / 已完成·空闲），圆点 + 文字，语义色映射不变（`STATUS_COLOR_KIND` 逻辑不动）；
- **品牌点缀四式**（用户可配，作用于看板/历史会话卡）：左彩檐（默认）/ 顶部细线 / 淡底渲染（`color-mix` 7% 品牌色染卡底，旧 WebView 回退为无 tint）/ 无檐纯图标；审批红卡不吃点缀（语义优先），但夜间主按钮反白适用；
- **中性 chips**：工具过滤 chips 去品牌实底，白/卡底细边框，选中近黑（夜间 `--btnp`）；
- **双层字体**：UI 字体随档位（标准/终端/圆润/书卷，系统字体栈），代码/路径/命令/时间戳恒 `--font-mono`；
- **图标纪律**：全部 SVG 线性图标（lucide），清除 emoji 图标（🕘 历史等）。

## 4. 页面规格（视觉以参考稿 01/02 为准）

1. **看板**（01）：品牌行 → 标题行（历史/提示音/主题三枚 SVG 图标钮 + 计数）→ 错误横幅（网络异常，amber 淡底保留）→ 跃迁横幅（保留现有行为，样式收敛为中性淡底）→ chips 行（折叠/展开机制保留）→ 会话卡列表（檐色 + 图标 + 工具名 + 项目名 + mono 时间 + 关闭/归档钮 + 标题 + 消息预览 + 状态徽标）→ 空态。**数据流、SSE、轮询、提醒三件套逻辑零改动**，纯样式重构。
2. **会话详情**（02-A）：头部（返回 + 项目名 + 工具·会话副标 + 状态徽标 + 分屏/进度/刷新）→ 书签栏 → 消息流（用户暖灰气泡右对齐 / 助手无气泡纯文本 / 工具调用与结果折叠行 / 思考行 / 计划卡）→ 审批红卡（红边 + 等待批准 + mono 命令块 + 允许/拒绝 + 降级脚注）→ 输入区（＋ / 输入 / 主按钮发送）。交互逻辑（分屏、书签、队列、注入回执）零改动。
3. **问答卡**（02-B）：题干 + 选项行（选中近黑描边 + 实心圆点）+ 自由作答 + 「勿在终端按回车」提示。
4. **文件面板**（02-C）：来源筛选分段控件（全部/我上传/工具读取/工具写入）+ 路径 mono 行 + 改/读徽标 + 档位切换。
5. **历史归档 / 归档详情 / 配对页**（02-D）：历史行带真图标 + 移回钮；配对页近黑主按钮 + PIN mono。

## 5. 外观设置（参考稿 04）

设置 → 外观页改为**两个独立大框**（无 Tab，行为差异写在标题栏）：

- **框一 桌面端外观**：徽标「仅本机 · 即点即生效」。内容 = 现有主题（浅色/跟随系统/深色）+ 语言，原样搬入，无保存键。本期不改桌面端样式本身。
- **框二 远程端外观**：徽标「保存后下发 · 已配对 N 台」。默认折叠（摘要 = 白天/夜间皮肤色点 + 字体 + 下发状态），点击展开完整配置器：
  1. 字体气质四档（chip 文字以自身字体渲染，自证样式）；
  2. 皮肤六色板：白天 3（暖白纸感/极简纯白/雾青）+ 夜间 3（暖黑纸感/极简纯黑/深青），**各组必选其一**（4 选 2 口径，不允许空，默认纸感对）；
  3. 卡片圆角：8/12/18/22px；
  4. 品牌点缀：左彩檐/顶部细线/淡底渲染/无檐；
  5. 预览区两列（左白天右夜间）× 四排（看板/对话流/审批卡/文件面板），随选项实时重渲（复用 Token 变量渲染，与真实端同源）；
  6. 保存条：改动 → 「● 有未保存的更改」黄标 + 「保存并下发」点亮；点击 → 写库 + 下发 + 「✓ 已保存并下发」；不自动生效。

## 6. 技术方案

1. **Token 落地**：`mobile.css` 定义变量与六张皮肤表；组件样式从 `dark:` 双态类迁移为语义变量类。日/夜切换沿用现有 `theme.ts`（localStorage + 系统偏好 + mobile.html 防闪脚本），防闪脚本扩展为同时应用已保存的皮肤/字体/圆角/点缀（localStorage 镜像，键 `mam-ui-config`）。
2. **配置存取**：SQLite 新表 `remote_ui_config`（单行：daySkin/nightSkin/font/radius/accent + updatedAt）；命令 `remote_get_ui_config` / `remote_set_ui_config`；HTTP `GET /m/api/v1/ui-config`（配对鉴权，403 同既有口径）；mobile.html 首帧内联 fetch 失败 → 落 localStorage 镜像 → 再落默认纸感对（三级回退，不阻塞首帧）。
3. **外观设置 UI**：`pages/settings.tsx` appearance 节重排为两分区；新增 `RemoteAppearanceSection.tsx`（配置器 + 预览）。预览实现直接消费同一份 Token 表常量（TS 常量 = mobile.css 变量值的单一来源，构建期注入 CSS，避免两处漂移）。
4. **ToolIcon 重绘**：按台账矩阵重绘 6 个 SVG（路径级自绘，不临摹官方素材）；`--tool-*-bg/fg` 双端变量表同步；WorkBuddy/Kimi 白天形态不变。
5. **回归面**：看板/详情全部交互（SSE、注入回执、队列、审批、文件预览、书签、振动提示音）不改逻辑只改样式；现有 vitest 用例中选择器若依赖样式类需同步更新；新增用例：ui-config 存取命令、GET 接口 403/回退、防闪脚本三级回退。

## 7. 验收标准

- [ ] 三份参考稿（01/02/04）逐屏对照通过：默认白天 = 暖白纸感，默认夜间 = 暖黑纸感，视觉误差仅允许像素级；
- [ ] 六皮肤 × 日夜切换无文字/边框对比度不足（WCAG AA 4.5:1 抽查）；
- [ ] 字体四档切换：UI 文字变、代码/路径/时间戳恒 mono；
- [ ] 品牌点缀四式生效且审批卡不受影响；淡底渲染在无 `color-mix` 的 WebView 回退为无 tint 不报错；
- [ ] 外观两框行为正确：桌面端即点即生效无保存键；远程端改动→保存→刷新 PWA 生效；未保存关闭展开不丢改动提示；
- [ ] ui-config：未配对 403、保存后 GET 返回新值、三级回退生效；
- [ ] 全部 emoji 图标清除；`pnpm check` 与 `pnpm test` 全绿。

## 8. 已知限制（如实申报）

- 圆润/书卷档依赖 Apple 系统字体（Yuanti SC / Songti SC / New York），Android 等平台回落标准档；
- 淡底渲染依赖 `color-mix()`（Safari 16.2+/Chrome 111+），旧 WebView 回退无 tint；
- 单选题选中态的终端屏读边界（现有裁决）不在本 spec 范围。
