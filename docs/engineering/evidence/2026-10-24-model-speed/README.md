## 定稿前源码核查增补

- [原生计时边界](native-timing-addendum.md)：纠正Kimi原生工具duration遗漏，确认审批在call之前、重试首点未重置及各源首输出边界。
- [遥测边界](otel-boundaries-addendum.md)：确认Claude消息/内容块起点及Codex首item计时不等于首非空输出。本版不增加遥测接收器。
- [DSH总输出scope](dsh-output-scope-addendum.md)：补齐原生计数映射和持久replay profile证据，仅明确profile可进入TPS，其他profile返回空值。

上述增补和正式设计取代初轮报告中尚属候选的能力判断；初轮覆盖率保留为探测快照，不能视为首版正常指标的准入率。

## 复跑与隐私

- 报告各自列明路径发现、读取预算、样本分母和只读 SQL / 结构扫描方法；不输出会话正文、密钥、工具参数或完整响应。
- SQLite 使用只读连接并尊重 WAL；文件先 stat 再按预算读取，mtime 仅用于选样。
- 活动工具可能同时写入数据，不同探测快照计数不同属正常情况；比较时应固定快照和分母。
- 完整复跑需同时核对版本和源路径覆盖；本机样本不能推断其他平台、旧版或未来版的行为。
- 报告放在 `evidence/` 下，避免项目 `.gitignore` 的 `research/` 规则将设计证据排除出版本控制。
