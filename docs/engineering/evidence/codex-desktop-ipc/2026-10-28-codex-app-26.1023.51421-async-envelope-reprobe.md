## 4. 失配根因（一手核对）

旧 `AsyncAnswerIdle` 规则的十条 `requires` 里，`question:r.P(),answer:r.P()`、
`startsWith(uxe)`、`endsWith(dxe)` 三条在本包**不存在**，其余七条全部存在；
版本表 `thread-follower-start-turn=2` 也在。即：协议未变，只是压缩器局部名被当成了
契约。其余五项操作在本包上**仍匹配**——它们的规则同样含 `t.params`、`e.startTurn`
这类形参／接收者字面，只是本版这些字面恰好未变；本次只解决异步答题的改名容忍，
**不**承诺五项对未来压缩器改名稳健。与 `mam.log` 2026-10-28 19:34:59 记录的
"五项匹配、无 AsyncAnswerIdle"一致。
