# 用量统计

每个工具各烧掉多少 token——一条账本看得清，自动采集、只读本机、无遥测。

## 用量账本

兔维斯为 Claude Code / Codex / Kimi Code / OpenCode / ZCode / WorkBuddy / dsh 七个工具统一记账（OpenClaw 暂不采集）。**只在本机读取各工具自己的会话记录汇总**，不上报任何遥测；账本存 `~/.tuvis/tuvis.db`，明细按小时桶默认保留 90 天（可配），到期只留日聚合。

采集节奏：应用启动后延迟自动采一次，之后按设置间隔进行（单飞互斥 + 最小间隔兜底，不占 3 秒会话轮询）；**设置 → 用量统计** 里可随时「立即采集」，也有总开关——关闭后不采集、不落库（设置与导出仍可用，导出的是既有账本）。

## 打开大看板

主窗口**标题栏的用量按钮**打开独立的用量大看板窗口；桌宠迷你条的「详情 »」也可直达。

![用量大看板](../img/usage-dashboard.png)

大看板包含：

- **指标网格**：token 总量（四桶）、命中率等核心指标，带与上一等长周期的环比；
- **趋势卡**：折线 + 渐变面积图，x 轴粒度随时间范围切换，右上角标峰值、悬停看精确值；
- **分组分布卡**：按 **工具 / 项目 / 供应商 · 模型** 三维切换的占比条排行；
- **工作小结**：会话数、turn 数、报错次数、最长单 turn、工具调用，不可得显示空态而非 0；
- **导出**：复制文本 / 导出图片（分享图，含桌宠立绘）/ 导出 CSV（UTF-8 BOM，Excel 兼容，只含结构化账本列）。

时间范围五档可切，自定义起止跨度 ≤31 天。同窗口的「用量记录」页签：每工具一卡，每行 = 「供应商 / 模型」的消耗，可按工具 / 项目分组，带 实测 / 推断 / 未知 标记。

## 迷你条

悬停桌宠约半秒出现的浮窗即迷你条（宠物右键「今日用量」可唤回）：5 行指标行序钉死（请求 + 命中率 / 缓存命中 + 产出 / 四桶明细 / 报错 / 最长单 turn），时间档（当日 / 近 5 小时 / 近 7 天）与工具行数（1–7）随设置联动，尾部「详情 »」直达大看板；**设置 → 用量统计** 的「今日口径」与之同源。

## 采集口径速览

- **四桶** = 未缓存输入 / 缓存读 / 缓存写 / 产出；命中率由缓存语义（互斥 / 包含 / 仅总量）派生，拿不准时按互斥——宁可命中率偏低，不静默多算；
- **含子代理**：token 总量包含子代理用量；turn 数不跨工具合计；
- **不可得显示 `—` 而非 0**：部分指标仅部分工具可得（如「用户输入(估)」仅 claude / codex / kimi）；
- **隐私**：界面与 CSV 只出现结构化数字与工具 / 模型 / 项目 / 会话标题，无 prompt 原文，无代码内容。

> 💡 某列显示 `—` 不是故障，是该口径下真值不可得；命中率超过常识时多半是缓存语义误判，反馈时请附工具版本号。
