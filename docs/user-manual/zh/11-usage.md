# 用量统计

每个工具各烧掉多少 token——一条账本看得清，自动采集、只读本机、无遥测。

## 用量账本

兔维斯为 Claude Code / Codex / Kimi Code / OpenCode / ZCode / WorkBuddy / dsh 七个工具统一记账（OpenClaw 暂不采集）。**只在本机读取各工具自己的会话记录汇总**，不上报任何遥测；账本存 `~/.tuvis/tuvis.db`，共 4 张表（明细按小时桶、日聚合永久保留、采集游标、会话维度），明细按小时桶默认保留 90 天、上限 90 天（可配），到期只留日聚合。

采集节奏：应用启动后延迟自动采一次，之后按设置间隔进行（单飞互斥 + 最小间隔兜底，不占 3 秒会话轮询），前端也可通过 `usage_collect` 按需触发（默认 10 分钟的最小间隔兜底）；**设置 → 用量统计** 里另有「采集状态」分区，提供采集状态自查与「立即采集」入口，以及总开关——关闭后不采集、不落库（也不做保留期清理，看板 / 记录页查询走关闭态早退；设置与导出仍可用，导出的是既有账本）。数字设置（迷你条工具行数 / 明细保留期 / 采集间隔）在输入过程中保留草稿，**失焦或按 Enter 后才夹取并保存**，不会边打字边改值。

## 打开大看板

模型用量是主窗口四个一级页签之一（消息看板 / 工具资源 / 模型用量 / 输出速度）——点页签即达；原标题栏的用量按钮保留在标题栏，点击直达模型用量页签；桌宠迷你条的「详情 »」等旧详情入口也统一唤起主窗口并选中模型用量页签。

![用量大看板](../img/usage-dashboard.png)

大看板包含：

- **Token 总览**（固定展开）：总处理 Token、新增输入、缓存命中、未缓存命中输入、输出、命中率、请求次数，带与上一等长周期的环比；原「缓存写入（解释）」块已移除，计量维度统一为「新增输入 / 缓存命中 / 输出 / 合计」；
- **用量趋势**（固定展开）：折线 + 渐变面积图，x 轴粒度随时间范围切换，右上角标峰值、悬停看精确值；卡内可按「全部 / 按工具 / 按渠道」局部筛选，峰值与环比跟随同一筛选口径，但**不影响全局总览与分布**；其中「渠道」= 供应商别名（provider 显示名，未编辑 = 原名；显式计费绑定优先；工具不参与渠道分类；未配置别名时非空 provider 按原始串聚合；「未指定渠道」与「渠道可能混合」不作为筛选选项）；
- **用量分布**（默认展开、可折叠）：按 **渠道 / 工具 / 项目 / 模型** 四维切换的占比条排行，默认 Top 5，可「显示更多」；每行 = 名称 · Token · 缓存命中率 · 相对条，不显示美元金额；同显示名跨工具合并，同名模型不再出现无法区分的重复行；空 provider 未指派时渠道维度合并为「未指定渠道」一行、模型维度按工具拆行；渠道维度另有「渠道可能混合」行（同一日志身份可能混合多个账户、无法拆分）；空模型显示「未知模型」；
- **API 等效费用**（默认展开、可折叠）：每条模型一张卡片，主行五列（渠道 / 模型 | 估价 | 总 Token | 缓存命中率 | 计费详情），默认按渠道分组、可切按模型平铺；没有全局费用总额或渠道小计（费用不是实际支出）；同一归一化模型同币种同价，不同显示渠道分行展示；卡片内展开「新增输入 / 缓存命中 / 输出 / 合计」四行 ×「项目 / Token 用量 / 金额 / 单价」四列的计费明细（合计行单价留空，缓存写仅有数据时出现），主表头与明细列头均为实体字，小字只留归一化模型与快照获取时间，不准确原因一行用 `·` 分割；卡头「同步价格」可手动强制刷新 models.dev + 人民币来源 + 当日汇率（loading / 行内状态）；表头可 USD / CNY 快捷切换（只换显示，账本与费用 CSV 仍为 USD）。**CNY 优先原生人民币价，缺失时按当日汇率换算；原生价正常显示，换算价加虚线下划线（卡头有图例）**；
- **工作活动**（默认折叠）：卡头显示会话数与工具调用次数；展开后看 turn、错误三层、用户打断、最常调用工具，p50 / 最长 turn / 工具耗时收在展开后的高级统计里；
- **导出**：复制文本 / 导出图片（分享图，含桌宠立绘）/ 导出 CSV（UTF-8 BOM，Excel 兼容，只含结构化账本列）/ **费用 CSV**（当前时间窗全部渠道 / 模型费用行，不含总计，前端不加 BOM；在既有 17 列后追加渠道键 / 渠道类型 / 显示名 / 归一化模型 / 目录发布日期 / 覆盖价标记 / 价格规则形态 7 列；`observed_provider` 单值列在合并多个原始 provider 或含未标注来源时留空，完整证据见 UI tooltip）。分享摘要已删除「用户输入(估)」，并新增「未缓存命中输入」。**导出设置 → 出图模块**可选分享图画哪些段：总览 + 趋势图必选不可关；分组分布按工具 / 项目 / 供应商 / 模型四维多选，每选一项多出一段 Top 6；「API 等效费用」（合计估价 + Top 行）与「工作小结 + 桌宠发言」（工具格 + 立绘气泡）各自开关。勾选即保存、只记在本机（浏览器 localStorage），只影响导出的图片，「复制文本」摘要不变。

时间范围五档可切，自定义起止跨度 ≤31 天。同窗口的「用量记录」页签：每工具一卡，每行 = 「供应商 / 模型」的消耗，可按工具 / 项目分组，带 实测 / 推断 / 未知 标记；**行名优先显示供应商别名**（「别名 / 原始模型」；无别名回退原始「供应商 / 模型」，原始身份保留在 title 与行数据中）；**「用量分布」的渠道 / 模型维度与「API 等效费用」行 tooltip** 展示原始 provider 证据——合并多个原始 provider 时列出完整列表，组内有非空 provider 且含未标注来源时追加「含未标注来源」提示（工具 / 项目维度不展示 provider 证据）；普通行不再出现「指定渠道 / 修改关联」，只有含糊行显示「绑定计费归属」；旧版计费归属与参考价规则收在页脚「高级」入口；行仍带「用户指定 / 日志实测 / 含糊」轻量标记；每行另有「供应商显示名」入口（已有别名时显示「编辑」），浮窗保存前可预览该规则近 30 天的命中工具、模型与 Token 合计。**设置 → 用量统计 → 显示与计价配置** 与「自定义价格规则」放在**同一个弹窗**（费用卡「管理配置」直接打开同一弹窗）：设置页与 D 卡共用，弹窗上半是供应商/模型条目，下半是可折叠的自定义价格规则（默认收起）；设置页与 D 卡是两个 WebView，设置页修改后已打开的用量看板不保证立即刷新，看板内配置是主路径。条目默认按最近 7 天 Token 用量显示前 10，可按用量 / 原始供应商名 / 原始模型名排序（同键切换升降序），底部可展开全部并搜索；每条三行——原始身份（只读）、供应商名 + 模型名（都可编辑：供应商名对同一原始 provider 全局生效，空 provider 条目写 toolModel 别名；模型名按（显示供应商, 原始模型）批量生效）、计价身份（仅下拉 / 搜索选择）。高级区「自定义价格规则」支持固定价或分时价（可选 USD/CNY 计价币种）；计费归属绑定 / 参考价规则是旧版能力，入口已移至「用量看板 → 记录」页页脚的「高级」入口。每个高级选项旁有 Info 图标，hover/focus 显示说明；每条模型有「设置自定义价格 / 编辑自定义价格」快捷入口，自动预填原始模型名（保存时后端归一化），已有规则显示「已应用自定义价格」徽标。**定价目录状态** 仍在设置页，可启用 / 刷新 models.dev 公开价目，失败沿用最后有效快照。

## 供应商显示名（别名）与自动定价

- **渠道显示名**：渠道 = 供应商别名。非空 provider 按原始串精确映射到别名，未编辑 = 原名；不同原始串可映射到同一显示名并跨工具合并；显式计费绑定优先级最高；别名只影响展示与分组，不回写账本，也不改变 Token 口径。**未配置别名时，非空 provider 按原始串聚合**。记录页行名优先显示供应商别名（原始「供应商 / 模型」保留在 title 与行数据中）；别名同时体现在「用量趋势」筛选项、「用量分布」「API 等效费用」、配置弹窗与别名浮窗中；「用量分布」的渠道 / 模型维度与「API 等效费用」行 tooltip 展示原始 provider 证据——合并多个原始 provider 时列出完整列表，组内有非空 provider 且含未标注来源时追加「含未标注来源」提示（工具 / 项目维度不展示 provider 证据）。
- **空 provider**：不设自动规则，按「工具 + 原始模型」逐条设置别名，保存后回溯生效；未指派时渠道维度显示「未指定渠道」（合成一行）、模型维度按工具拆行；空模型显示「未知模型」。
- **供应商名与自定义模型名**：配置弹窗的供应商/模型条目段可同时编辑供应商名与模型名。供应商名对同一原始 provider 全局生效（空 provider 条目写 toolModel 别名，未命名 = 未指定渠道）；模型名可一键复制原名、可清除回原名，显示名键 =（显示供应商, 原始模型），同一展示键的多个原始来源一起改名；自定义模型名只应用在 D 卡行名上（C 分布与记录页仍显示原始模型名；记录页的供应商部分会显示别名）。
- **计价身份**：可为模型条目显式指定目录 provider / model——仅下拉 / 搜索选择，无自由输入，避免非法键；默认显示精选自动匹配结果，可覆盖、可清除；优先级低于自定义价格规则与参考价规则、高于自动匹配。
- **已知限制**：两个订阅在日志中的原始 provider 串完全相同时，别名无法把它们拆开，渠道会合并；只能靠含糊行的「绑定计费归属」或页脚「高级」入口（显式计费绑定），不按 Token 比例拆账。
- **自动匹配（精选来源）**：仅使用 models.dev 公开价目（不内置种子价），精选来源按「直营官方（含中国站变体）> OpenRouter」取价，四价全 0 的条目跳过；模型 ID 机械归一化后精确匹配，层内按 `release_date` 最新去重后同币种同价；精确未命中时前缀回退仅在唯一，或命中多个候选但价格完全一致时采用；跨模型族替代须显式指定参考模型。多模态 / 上下文阶梯等条件价按基础文本价估算，并在不准确原因里标注；缺价仍显示 `—`，不显示 0。精选未命中的模型默认未估价，可在计价身份里显式选择目录条目（目录搜索默认精选，可开「显示全部 N 个来源」查看全部来源）。
- **费用计算粒度**：近 7 天 / 近 30 天 / 自定义（≤31 天）的费用按小时明细按日聚合计算，dsh 也能按输入 / 缓存命中 / 输出全量计价；存在分时规则时按小时判定峰谷后再汇总，分时行单价为加权平均。明细保留期调低或清理导致范围内缺明细时，该时间段**整体回退日聚合**（dsh 仅按输出计价；分时规则按低谷价估算并标注）；近 5 小时 / 当日与计费渠道预览不变。
- **刷新与核对**：默认每日刷新、可手动刷新（D 卡「同步价格」可强制刷新 models.dev + 人民币来源 + 当日汇率）；失败沿用最后有效快照，并显示数据源与快照日期；D 卡行展开的小字可核对归一化模型与快照获取时间。**模型发布日不是价格日期**——目录条目的发布日只用于同名去重，估价始终采用快照获取时刻的价格。
- **自定义价格规则（固定价 / 分时价）**：在配置弹窗「自定义价格规则」里按**归一化模型名**设置价格。固定价直接覆盖输入 / 缓存读 / 缓存写 / 输出四价（USD / CNY，按所选币种存储；显示另一币种时按当日汇率换算并加虚线下划线）。开启分时价后，周一至周五的高峰窗口（可多个、可跨午夜、只支持整点）使用高峰四价，其余时间（含周末）使用低谷四价；低谷留空的分量回退目录报价；时区可选上海 / UTC / 系统本地，只影响 API 计费峰谷计算；可用「按高峰 × %」快捷填充低谷价。**不需要写供应商**；自定义显示名不参与匹配；保存后所有渠道的同名模型共用；它不在计价身份或参考价规则里选择。列表展示目录来源、发布日期与快照日期；后续价目同步不会覆盖用户值；日聚合回退时整段按低谷价估算并在不准确原因里标注。

## 近期 TPS（短时抽样）

> 📌 **形态更新**：本节描述的「近期TPS」独立区块已由主窗口第四个页签 **「输出速度」** 取代（区间双指标 + 采集管理一体，见下一节）；本节保留的口径原则——抽样非全量、空窗不补 0、不发送测速请求、一次配置自然重启——由输出速度页继承，具体数值规则以输出速度页与新设计稿为准。

大看板新增独立「近期TPS」区块：近期**已完成调用**的采样吞吐曲线（近2分钟 / 近10分钟 / 近1小时 / 当天，默认近1小时）、「最新有效完成调用」与「最近一轮」两组样本指标（样本模型用时 / 样本工具调用用时 / 样本平均首token / 样本TPS）以及各来源状态。它是**短时抽样，不是全量统计**，读数前请先理解以下口径：

- **抽样非全量**：每个采样点只取该点之前 120 秒内**完成**的有效调用（每条曲线最多最近 20 条），点内 TPS = 1000×Σ输出Token ÷ Σ生成毫秒。横轴是实际采样时间——兔维斯没在看的时段没有采样点，曲线不插值补线、不把空窗连成连续实测线；**不提供多天 TPS**，事实与采样点只保留最近 24 小时；
- **不是服务器基准**：全部数字来自本机端侧采样（各工具自己的记录或本机事件），**不发送任何测速请求**；「刷新」只读取已有事实，用户正常使用工具才会产生新样本。生成中的精确瞬时速度不在本版承诺内；
- **只含上报思考**：Token 口径尊重各源原生上报——供应商输出已含思考时不再相加；无单列思考计数时显示「思考计数未单独声明」，不按字符估算隐藏思考，也不宣称测得隐藏思考的独立速度；
- **计时方法分族显示**：流式实测（stream-observed，逐增量观测）/ 客户端原生（client-native，宿主自带原生计时字段）/ 原生事件近似（native-event-approx，带「原生近似」标记——首点取内容块开始时刻，近似值）。不同方法不合并成一条连续精确曲线，tooltip 标明方法；
- **空窗与更新时间**：没有有效样本的时段保存为 gap（空窗），**不画 0**、不沿用旧速度制造新点；「样本结束」是最新样本的结束时刻，「N 分钟前」是它的年龄；超过 10 分钟不再当当前值，显示「暂无近期样本」（历史点仍可查看）；每次兔维斯启动生成新采样段，退出期间没有实时点；
- **来源与一次配置**：ZCode / dsh / Kimi 为原生只读（随用量总开关自动生效）；Claude 与 OpenCode 需在「近期TPS」区块内**一次点击安装**（统计配置 / 观察插件）——预览确认后写入，提示「下次启动生效」，**兔维斯不会替你重启 Harness**；安装不改 API、认证或供应商配置，敏感统计头只显示脱敏值；卸载只处理兔维斯自己安装的项，你后来手改的内容会保留并提示冲突；
- **Codex 缺口（如实申报）**：Codex 的 metrics 管道已通，但当前没有同调用的可靠生成窗，**本版不提供 TPS**（来源状态明确标注）；其既有 Token/费用统计不受影响；
- **当前边界**：WorkBuddy 的 Windows 路线暂因证据不足不产出 TPS（Mac 正常路线已支持）；OpenCode 观察插件安装并自然重启后产生样本；Windows 平台的 TPS 验收留待最终平台验收。

## 输出速度（区间双指标）

![输出速度看板](img/output-speed-board.png)

主窗口第四个页签「输出速度」提供**两条独立的端侧速度口径**：左侧「工具 · 模型 · 渠道」组合列表（按工具筛选，点列表表头的「组合 / 速度 / 有依据的会话数」可直接按该列升序或降序排序），右侧大图与四格指标（当前模式速度 / 首Token平均等待 / 累计用时 / 工具累计用时）；详情顶部的**组合名就是可选框**，不点列表也能直接切换组合。四档区间可切（近15分钟 / 近1小时 / 近5小时 / 近24小时，默认近5小时），悬停曲线看该桶读数、点击固定，Esc 或点「返回区间汇总」解除；列表里把鼠标停在组合名上会**立即**浮出完整名称（窄列被截断时尤其实用）。它是**已采集有效子集的区间统计，不是全量监控**，也不发送任何测速请求——读数前请先理解以下口径：

- **两种速度口径**：「流式输出速度 / TPS」= 1000×Σ流式有效输出Token ÷ Σ生成毫秒（不含首个Token前的等待）；「响应吞吐（含等待）/ Token/s」= 1000×Σ响应有效输出Token ÷ Σ含等待响应毫秒（分母含首Token等待与该来源边界内的准备/排队开销，不含响应结束后的工具执行）。同一记录两条口径独立判定有效性、独立计样本数，聚合一律 Σ/Σ，不平均单次速度；同一条 100 Token、等待 1 秒、生成 4 秒的记录，流式 25 TPS、响应 20 Token/s——两者都真实，只是分母不同；
- **来源能力如实标注**：六个原生来源（DSH / ZCode / Kimi / WorkBuddy Mac / Claude / OpenCode）双指标各有有效子集——「支持」指具备计算路径，不表示每条记录都齐全；**Codex 仅提供响应吞吐**：以原生响应ID对齐的日志输入/生成边界近似（显著标注「含等待 · 日志近似」），选中 Codex 时视图临时切到响应口径并说明缺口；流式生成窗暂缺、逐响应首Token等待也不可得——四格中「首Token平均等待」显示「—」，回合级数值不冒充该值；
- **工具累计用时当前为「—」**：只有能可靠归属到当前模型调用的工具时长才会累计，现有来源普遍不提供该归属（悬停该格可见此说明）；模型用量页的原工作活动统计（全工具口径）不受影响；
- **采样非全量、空窗不补 0**：区间与时间桶只聚合已采集的有效调用，没有有效样本的桶保持空——不画 0、不推算；图上实测线断开处用灰色虚线**仅作视觉连接**（图例「虚线仅连接，无样本」，可选严格断开样式）；失败、取消、无法对齐的重试不入任何速度，但可计时的失败/取消会计入「累计用时」与详情里的候选/失败/取消计数，速度 n 与累计用时因此不必相等；
- **24 小时事实窗**：区间基于最近 24 小时的原始数值事实聚合（按完成时刻归属时间桶），不做提前降精度、不提供更早历史；区间里没有记录是数据空态，不自动等于采集故障（来源接入状态看「采集管理」）；
- **四页同窗入口**：输出速度与消息看板 / 工具资源 / 模型用量同为主窗口一级页签，切页不停止会话监控与通知，各页区间与选中状态独立保留；速度页默认近 5 小时，与模型用量的时间范围完全独立；应用在后台时采集降频（可见约 5 秒、后台约 600 秒节奏），展示桶宽不是采集间隔；
- **采集管理入口与自然重启**：速度页右上「采集管理」与 **设置 → 用量统计** 的采集管理是同一组件——来源列表按真实状态显示（已接入 / 待配置 / 待重启 / 待检查；Codex 显示「已接入 · 仅响应」）；接入 Claude、OpenCode 走预览确认（敏感统计头只显示脱敏值），提示「**下次启动生效**」，**兔维斯不会替你重启 Harness**；安装不改 API、认证或供应商配置，卸载只处理兔维斯自己安装的项；
- **WorkBuddy 兼容与恢复**：WorkBuddy 5.8.3 Mac 日志中数值为字符串形态的记录已兼容接纳（旧版本会整源跳过）；已升级用户旧游标越过的近期记录（最近 24 小时）会在升级后自动有界恢复并去重——只恢复速度事实，不动 Token/费用账本与其他来源。

## 采集口径速览

- **四桶** = 未缓存输入 / 缓存读 / 缓存写 / 输出；命中率由缓存语义（互斥 / 包含 / 仅总量）派生，拿不准时按互斥——宁可命中率偏低，不静默多算。各源语义不一致，**同一工具不同记录也可能不同**——Codex 逐条用 `total_tokens` 算术判定（本机实测：正确判据命中率 92.69%，一律按包含会得到 >100% 的荒谬值）；
- **总处理 Token = 新增输入 + 输出**；**未缓存命中输入 = 新增输入 − 缓存命中**（本期与上期同公式；「新增输入」即账本 requestTotal，口径不变、仅界面措辞统一）；
- **含子代理**：token 总量包含子代理/侧链用量；会话数与 turn 数按父子分层（不把一次对话算成多次）；turn 数不跨工具合计（各源判据语义不可比）；**最长单 turn 逐工具给 p50 + 最长，且含挂机、未剔除 idle**；
- **不可得显示 `—` 而非 0**：部分指标仅部分工具可得——WorkBuddy 无回合概念、无时长字段、供应商不可得；OpenCode 工具级错误不可得；kimi 的用户主动打断判据缺失；dsh 的报错与最长 turn 只能从原始会话日志取（**只有一部分会话仍留有原始日志**——比例不写死：覆盖率随机器与会话清理策略变化）。这类部分覆盖**不在界面表达**：取到的照常显示，取不到的位次是 `—`，界面**不设「部分覆盖」档**。V2 已从看板与分享摘要删除「用户输入(估)」（它不是 API Token），账本字段与 Token CSV 原始列保留兼容；
- **隐私**：账本查询与后续呈现面只出现结构化数字与静态文本（工具名、模型名、项目名、会话标题），无 prompt 原文，无代码内容；CSV 导出只含结构化账本列——**会话标题与原始路径不进 CSV**（UTF-8 with BOM，Excel 兼容）；
- **子代理标记只在小时档有真值**：分组行的子代理标记（`isSubagent`）在**小时档**给出 `true` / `false`；**日档与记录页卡内行恒为空态 `null`**（这两档的行维度不含会话，算不出）——空态**不得**当作 `false`（「不含子代理」）读；
- **报错三层分列 + 用户主动打断单列**：三层互不包含，相加没有意义；
- **「按项目」按记录归属**：一个会话文件可跨多个项目（同一条会话记录内的 cwd 才算它的项目），项目名与首页会话卡片同源（`projectName`）；Windows 上各源路径大小写形态不同，同一目录可能裂成两组；无 cwd 的记录落 `Unknown`。

> 💡 某列显示 `—` 不是故障，是该口径下真值不可得；命中率超过常识时多半是缓存语义误判，反馈时请附工具版本号。
