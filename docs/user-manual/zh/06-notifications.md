# 通知与提醒

人不在终端前，兔维斯替你盯着：状态变化三层提醒，重要的事不会沉底。

![通知浮窗](../img/notify-toast.png)

## 三层提醒

会话状态变化（含去重去抖）时，三条通道依次接力：

1. **系统桌面通知**：系统级通知，自带「查看会话」动作，点一下直达该会话终端；审批等待场景另有「前往审批」动作；
2. **通知浮窗**：应用内小卡片从屏幕角落弹出，点击卡片即跳对应会话的终端，几秒无人理会后自动收起；
3. **提示音**：Web Audio API 合成音效，无需额外音频文件。

## 提醒策略

全部集中在「设置 → 通知与桌宠」卡：

- **桌面通知**总开关：会话变为等待或完成时发送系统通知；
- **子 Agent 回报提醒**：默认开，可独立静默，不影响主会话自身提醒；
- **状态黄绿抖动 60s 节流**：子 Agent 运行期主会话状态常在黄↔绿间抖动——同会话同方向跃迁 60 秒内不重复提醒（红·等待提醒不节流）；
- **活跃子 Agent 在场静默**：子 Agent 引发的抖动跃迁默认不弹不响，由「静默子 agent 活动引发的状态提醒」开关控制。

> 💡 想先看看效果？点卡里的「预览浮窗」就地弹一个测试通知，不惊动真实会话。

## 音效

提示音分两级：先选**全局完成音**作默认，再为单个工具设**工具专属音**覆盖（可选跟随全局、静音或自定义）。每项都带「试听」按钮，选完点一下就知道响不响。

## 通知铃铛与历史

主窗口标签栏的铃铛聚齐所有通知历史：未读数以角标显示（超 99 显 99+），点开可翻阅、跳转，也可「清空全部」或只清已读。错过的横幅在这里总能捞回来。

## 开机自动启动

- 无历史数据库的新安装，正式版首次启动默认尝试开启；已有安装及旧品牌迁移不改动，注册失败可在设置中手动重试；
- 设置页「通知与桌宠」块、以及系统托盘「显示窗口」项下方，两处均可开关——共用同一条读写路径、勾选态回环一致；
- 开关显示的是**系统里的真实状态**（Windows 读注册表启动项，含任务管理器里的启用/禁用标记；macOS 读登录项），界面显示即实际状态，不落本地缓存、不会漂移；开关失败回滚并如实报错；
- 自启拉起时主窗口**静默进托盘**、桌宠照常跟出（不会开机弹一屏）；
- Windows 卸载时由安装器钩子清理该用户的启动项；macOS 无卸载钩子，需手动移除 `~/Library/LaunchAgents/` 下对应的 plist。
