# 桌宠

内置桌宠常驻屏幕一角，替你盯会话：状态、用量、语音提醒一起带上。v0.5.8 起默认是
**tuvis-3D**（3D 科技兔），也可一键切回 **Foxbell**（小狐狸）。

![桌宠](../img/pet-window.png)

## 桌宠是什么

默认桌宠 tuvis-3D 是一只悬浮在屏幕角落的 3D 科技兔（Foxbell 则是小狐狸），能力完全一致：

- **头顶状态卡片**：与看板同色同义（红＝等操作 / 黄＝运行中 / 绿＝已完成），点卡片直接跳到对应终端；
- **用量贴片**：悬停宠物约半秒弹出浮窗，状态卡之外还有 token 用量迷你条（新增输入 / 缓存命中 / 输出 / 分工具汇总等核心行）；鼠标移开后留 2 秒宽限，够你从容点「详情 »」；
- **语音提醒**：等待时撒娇催促、任务完成求夸，字幕与语音时长自动对齐；双击还能与它闲聊。

## 切换内置宠物

「设置 → 通知与桌宠 → 切换宠物」里内置列表 tuvis-3D 第一、Foxbell 第二，点击即热切换、
无需重启应用。从旧版本升级上来的用户，之前的宠物选择会自动保留；内置宠物不会被外部同名
导入覆盖。

## 显隐开关：三处都通

1. **标题栏齿轮旁**的 🦊 按钮；
2. **系统托盘**菜单的「显示/隐藏桌宠」；
3. **设置 → 通知与桌宠**卡的「开启桌宠」开关。

三处互通，任何一处都能开能关。

## 启动时跟出

「设置 → 通知与桌宠 → 启动时跟出」默认**开启**：软件每次启动，桌宠都会自动跟出——哪怕你上次把它藏了起来。想让它开机先别出，关掉这个开关即可；运行中临时藏一藏，用上面三处显隐开关就好。

## 置顶

「悬浮在所有程序最前」开关（设置页与桌宠右键菜单均有）决定小狐狸是否压在所有窗口之上；置顶开启时会自动抑制通知浮窗，二者不打架。

> 💡 右键菜单还有出声 / 字幕 / 物理坠落 / 大小三档等开关，随时可拨。物理坠落自 v0.5.8 起
> **每次重启应用默认关**（会话内可再开，多窗口同步不变）。

## 宠物管理

![切换宠物](../img/pet-switch.png)

设置页「通知与桌宠」卡内有「当前宠物」「切换宠物」「导入宠物」「修改宠物」入口。**切换宠物**是窗口热切换，无需重启应用；删除或切换后，活动宠物会自动恢复。

![导入宠物](../img/pet-import.png)

点「导入宠物」进三步向导，来源三个标签任选：

1. **从 codex 导入**：列出本机 `~/.codex/pets` 下的可用宠物，直接勾选；
2. **文件夹 / 压缩包**：选本地宠物目录或 zip 包；
3. **petdex 在线导入**：先到 petdex.dev 画廊挑，把宠物页链接（如 `https://petdex.dev/pets/capvolt`）粘贴进来即可下载暂存。

向导随后让你确认宠物名、展示名与描述，图集可先预览再落库。缺语音文件的宠物自动降级为纯动画，其余功能照常。
