# 兔维斯是什么

兔维斯（Tuvis）是一块能**看清并掌控所有 AI Agent** 的桌面看板：开源（MIT 许可证）、local-first、无遥测，支持 macOS 与 Windows。

![兔维斯](../img/hero.png)

## 核心理念：监控 → 提醒 → 远程处置

1. **监控**：自动发现正在运行的各种 AI 编程工具会话，以红绿灯看板呈现状态、项目、分支、消息预览等信息，点击卡片直接聚焦对应终端；
2. **提醒**：状态跃迁时发送桌面通知与提示音，系统托盘图标同步聚合变色——重要状态不再淹没在一堆终端里；
3. **远程处置**：开启远程接入后，手机浏览器打开与桌面同源的看板，人不在电脑前也能看会话进展、收推送、发消息、批准计划，直至新建会话（发消息与新建会话为试验性能力）。

## 八种工具，一个看板

兔维斯目前支持八种 AI 编程工具。各工具的开放程度不同，能力如实对号入座（✅ 支持 / ◐ 部分 / 🧪 试验性 / ❌ 不支持）：

| 能力                  | Claude Code | Codex CLI | OpenCode | OpenClaw | Kimi Code | WorkBuddy | ZCode        | dsh   |
| --------------------- | ----------- | --------- | -------- | -------- | --------- | --------- | ------------ | ----- |
| 会话监控（红绿灯）    | ✅          | ✅        | ✅       | ✅       | ✅        | ✅        | ✅           | ✅    |
| 桌面通知              | ✅          | ✅        | ✅       | ✅       | ✅        | ✅        | ✅           | ✅    |
| Skill 管理            | ✅          | ✅        | ✅       | ✅       | ✅        | ✅        | ✅           | ◐ 只读 |
| MCP 管理              | ✅ JSON     | ✅ TOML   | ✅ JSONC | ✅ JSON  | ✅ JSON   | ✅ JSON   | ✅ JSON 子树 | ❌    |
| 手机 · 消息查看       | ✅          | ✅        | ✅       | ❌       | ✅        | ✅        | ✅           | ✅    |
| 手机 · 文件预览       | ✅          | ✅        | ✅       | ❌       | ✅        | ✅        | ✅           | ✅    |
| 手机 · 发消息（注入） | 🧪          | 🧪        | 🧪       | ❌       | 🧪        | ❌        | ❌           | ❌    |
| Token 用量            | ✅          | ✅        | ✅       | ❌       | ✅        | ✅        | ✅           | ✅    |

> 💡 表中 🧪 表示试验性能力：手机注入（发消息 / 新建会话）目前只对 Claude Code、Codex CLI、OpenCode、Kimi Code 四家开放。OpenClaw / WorkBuddy 属黑盒形态、没有外部写通道，因此「看得见、发不进」（OpenClaw 手机端不支持远程查看，只在桌面看板可见）——这是各工具开放程度的真实差异，不是故障；Token 用量一栏 OpenClaw 暂不支持采集。
