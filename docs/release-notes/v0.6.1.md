# v0.6.1 发布说明（2026-10-22）

> v0.6.0 正式版以来的全部变更：**远程接入两套固定地址向导完整落地**（Tailscale 与
> Cloudflare 自有域名按时间轴引导配置）、**全新安装默认开启远程接入与开机启动**、
> macOS 安装流程修复，以及四张通道卡的设计语言统一与等待过程提示。
> 升级后无需任何手动配置，升级用户所有设置与数据原样保留。

## 新功能

- **固定地址向导统一收尾**：Tailscale 与 Cloudflare 自有域名均按时间轴配置，公网看板
  实际核验通过后自动收起并保留地址、复制、打开、二维码与查看步骤入口；后续异常保持
  摘要，历史完成记录不冒充实时可用。
- **Cloudflare 自有域名向导**：以域名已接入 Cloudflare 为前提，引导创建隧道、粘贴
  Token、确认真实连接、浏览器绑定域名及验证访问；进程存活不再等同已连接，配置变更后
  须重新核验。
- **首次安装远程引导**：无历史数据库的新安装默认开启远程接入和开机启动，设备签名默认
  关闭；各通道仍手动开启。
- **Tailscale 安装体验**：安装包保存到系统下载文件夹，向导按时间轴对齐操作、完成变绿，
  校验成功才显示文件路径，自动下载失败才显示手动下载入口，复用有效旧包。
- **复验过程提示**：通道重新开启后的自动复验期间，摘要显示转圈提示与预期时长（通常
  几十秒到一分钟内恢复），复验通过自动消失；四张通道卡在完全可用时显示绿色卡片外观。

## 修复

- **macOS Tailscale 安装**：点击安装自动打开系统安装界面，返回应用后重探安装状态；
  取消不误报完成，安装器失败保留退出码和 stdout/stderr，修复空白「动作失败」。
- **Tailscale 开通收尾**：向导里开通 Funnel 成功即持久化通道开关位并写入审计，公网
  核验通过后可正常收尾，重启后按已开启恢复（此前开关位不落盘，完成门永远不成立）。
- **批准链接保留**：首次开通返回的浏览器批准链接不再被同配置普通状态刷新清掉；配置
  变更、通道关闭或总开关关闭仍会作废旧链接与在途回执。
- **DNS 等待与修复分离**：公网明确无记录时显示连续等待时长与约 10 分钟估时，自动只读
  检查，等待时不提供重复重试；普通校验不再重置 Funnel，明确确认的重新开通才执行修复。
  macOS 扩展已启用显示无需操作，后端停止不再误报为未批准。

## 升级须知

- **首次安装默认值只影响新安装**：全新安装（无历史数据库）远程接入与开机启动默认开启、
  设备签名默认关闭；升级用户保持原状态，关闭开关后不会自动重开。
- **历史完成记录不冒充实时可用**：升级后重新打开向导，若通道配置已变化会重新走核验；
  历史地址在当前检查通过前标为「暂不可用」，核验通过后恢复打开与扫码入口。
- **macOS 系统扩展已启用时直接显示「无需操作」**；后端停止时会先引导检查 Tailscale
  客户端，不再误报为未批准。
- 目前仅支持 Windows 与 macOS；Linux 尚未支持。
