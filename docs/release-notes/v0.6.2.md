# v0.6.2 发布说明（2026-10-26）

> v0.6.1 正式版以来的全部变更：**界面语言自动跟随**（桌面跟随系统、手动最后生效）、
> **手机端一键停止桌面 Codex 回合**、**Codex 未知桌面版本的兼容路径（实验）**，
> 以及 Windows 闪退与升级网络回退两处修复；双语 README 门面化 + 双社区渠道上线。
> 前三条为升级须知，请先阅读。

## 升级须知

- **界面语言一次性回落**：此前手动切换过界面语言的桌面端，升级后会一次性回落到系统
  语言，重新选择一次即可；从未手动切换过的用户无感知。
- **未知 Codex 桌面版本的兼容路径默认开启（实验）**：移动端对未知 Desktop build 默认
  开启「兼容发送（实验）」并自动只读探测（服务端 15 秒上限）；打断、审批等破坏性能力
  仍按证据门控。不需要可在设置页关闭「兼容发送」。
- **停止桌面回合会丢失该回合未完成的工作**：确认弹窗会如实提示，请确认桌面侧没有还在
  写的内容再操作。

## 新功能

- **界面语言自动跟随**：桌面端默认跟随系统语言、变化实时跟随；手动选择后以手动为准。
  手机端界面语言由桌面端下发，可在手机设置中手动覆盖（手动最后生效）。
- **手机端停止 Codex 桌面回合**：待发队列面板新增「停止桌面回合并继续」——一键打断
  当前桌面回合，队列自动接力发下一条。macOS `26.1013.40934` 已实测可用，其他 Desktop
  版本暂不开放。
- **Codex 桌面 APP 未知版本兼容（实验性）**：能力按三态徽标如实呈现（已验证 / 兼容发送
  （实验）/ 未解锁）；未知 build 默认开启兼容发送、自动只读探测（15 秒上限）后解锁，
  设置页提供开关与风险提示。

## 修复

- **远程开关与通道热重启闪退（Windows）**：关闭远程总开关或热重启通道不再触发
  0xc0000409 进程崩溃（停止收尾改经应用运行时派发）。
- **升级安装的网络回退与真实报错**：系统代理中途断开时，升级下载自动换 DoH 钉定直连
  重试，失败提示显示真实原因。
