# v0.6.8 发布说明

0.6.8 新增 DeepSeek Harness（DSH）远程操控。已配对设备可在 Tuvis 会话详情处理日常操作，也可以从当前远程入口打开官方控制台。

## 新增

- **DeepSeek Harness（DSH）远程操控**。在桌面远程设置中选择 Desktop／Web 实例，并通过一个开关完成插件安装、宿主重开和授权。关闭后先撤权，再等待宿主退出卸载。关闭失败时可重试。
- **DSH 手机原生会话**。发送文本与文件或图片附件，查看可验证的送达回执，停止当前回合，整组回答普通问题。增加「上一题」「下一题」、文件池、原生媒体与交付件预览，以及 macOS 子 Agent 只读详情。
- **DSH 官方会话设置与控制台**。会话空闲时可读取及切换权限、模型和思考强度。通过同一远程入口在新标签打开所选实例的官方控制台，保留原页草稿和滚动位置。
- **OpenCode 原生操控（macOS）**。会话通过官方原生路径发送、停止、交互和上传，保留绑定目录和原生队列状态。Windows 尚未接入原生写入。

## 修复

- Windows 窄矮窗口的更新提示可滚动阅读，标题、关闭和升级按钮保持可见。
- Codex 桌面远程停止和队列状态更新更一致。优先发送、空暂停队列恢复与消息来源切换有更明确的结果。
- OpenCode 附件写入保留已确认的精确工作目录，无法确认进程归属时拒绝终止。

## 升级须知

- DSH 首次使用请到桌面远程设置选择宿主并开启 DSH，按卡片实际状态完成安装和授权。修改模型或思考强度会更新该宿主配置的默认选择。执行及计划审批在官方控制台处理。
- 有隔离 macOS Desktop 发送和设置回读证据。Windows Web 实例归属尚未实现，Windows 原生流程、macOS Web 写入和四个远程渠道的真实控制台往返仍待复验。
- macOS OpenCode 远程写入使用原生接入，详情见产品手册。
