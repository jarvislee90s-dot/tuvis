# v0.6.7 发布说明

## Codex 桌面远程控制

- **异步题卡跳过与恢复**。单题可在 Tuvis 跳过，之后可恢复显示。符合条件的 Windows 会话还可尝试关闭桌面卡，页面分别显示两端的结果。
- **即时答题卡**。多题翻页更清楚，可在当前标签页收起和展开整张卡，在末题一次提交答案。
- **运行中答题**。在支持的会话中提交异步答案后，Codex 继续处理当前任务。桌面或远程完成正式作答后，匹配的题卡更可靠地同步撤下。
- **消息与队列**。消息送达状态更新更准确，单条插队结果和剩余队列更清楚，长会话中的答题状态更稳定。

## 远程页面

- 已配对设备可预览操作系统允许 Tuvis 读取的普通文件。
- 消息展开和加载历史入口随当前显示的消息来源切换，文件定位和回到最新更一致。

## 升级须知

Windows 上，Tuvis 最后确认可远程操控的 Codex Desktop 安装包是 `OpenAI.Codex 26.1106.6628.0`，该包最迟在 2026 年 11 月 11 日已有公开安装记录。后续 Windows 桌面版调整了 IPC，部分新版可能无法连接或远程操作。Tuvis 正在适配新版。若升级后遇到问题，可暂时回退到这个已验证版本，或你此前已验证可用的版本。 [公开安装记录](https://github.com/openai/codex/issues/60812)
