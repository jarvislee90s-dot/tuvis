# v0.6.6 发布说明（2026-11-06）

## Codex Desktop 异步答题

- Windows 新旧安装布局均可识别。补齐新版题目标识形态，修复「未匹配到异步答题契约」和普通助手消息导致远程不出卡的问题。
- 在 Windows Codex Desktop 26.1103.3517.0 的开发构建中，桌面和远程各正式作答一次，另一端均撤下对应题。普通聊天回复继续按聊天消息处理。
- 可在远程页收纳和恢复旧题组，当前页面的草稿保留。桌面直接跳过或关闭未答卡时，远程可手动收纳。

## 升级须知

- 升级后会用新规则重新识别契约，旧提示库会自动迁移。
- 远程异步题可以在回合运行中填写，待桌面空闲后由用户正式提交。运行中提交另行跟踪 [#203](https://github.com/jarvislee90s-dot/tuvis/issues/203)。

更多操作见[移动远程手册](../product/manual/zh/08-mobile-remote.md)。
