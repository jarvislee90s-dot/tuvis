# v0.6.5 发布说明（2026-11-04）

> 本版主打 **ZCode 全面功能接入**：Windows 实机取证收口、网络双路兜底、控制交互
> 显式化，外加用量估算与看板精度的几项增强。升级后历史数据与既有设置保留。

## ZCode：全面功能接入（Windows 实机验证）

ZCode 桌面端经官方桥接（单条 relay + BigModel OAuth 授权）把 workspace 和会话投影到
看板，手机端可以对 ZCode 会话做全部日常操作：

- **发送消息**：运行中发送自动进入本机待发队列（位次 + 摘要），支持再编辑、撤回、
  插队（先停当前回合再发这一条）和显式继续；编辑草稿可跨刷新找回。
- **应答阻塞问答**：单选、多选、自由文本三种题型手机端直接作答，作答后以终端屏读
  核对为准。
- **审批与计划**：命令/文件审批一次原生批准；计划模式可批准或填修改意见让宿主保持
  计划模式并反馈给 agent。
- **定向打断**：停止当前回合；打断不可执行时自动回退为发送兜底。
- **切换供应商 / 模型 / 思维档位**：按供应商分组选择，一次提交完整三元组。
- **切换协作模式**：计划 / 自动编辑 / 变更前确认 / 完全访问（完全访问需额外确认）。
- **控制不可用不影响阅读**：看板、正文与文件预览不依赖控制成功。

账号授权只在本机进行：BigModel OAuth 的账号 JWT 只存系统凭据保险箱（Windows 凭据
管理器 / macOS 钥匙串 / Linux Secret Service）与受控内存，不写设置、数据库、文件，
不进日志，手机端不持有任何凭据；重启自动恢复授权，不需要重复登录。

### Windows 实机验证

本版对 Windows 已安装的 ZCode 桌面端做了完整的实机取证（3.17.2.9661）：发送、问答
（单选 / 多选 / 自由文本）、打断、模型与思维档位切换、协作模式切换全部通过，本地
待发队列在 Windows 3.17.2 上也有实机链路。应用会自动识别已安装 ZCode 的四段版本号，
按版本逐项开放控制能力；官方升级 ZCode 后能力自动重算，不需要升级兔维斯。

## 网络：代理与直连双路兜底

Windows 上「系统代理开着、但代理隧道不通」是最常见的接入失败形态。本版：

- **授权与连接**：先走系统代理，传输失败自动改直连重试一次；
- **长连接**：先直连（只占一半预算，防挂起吃光兜底窗口），失败后自动读系统代理走
  CONNECT 隧道——证书校验与直连同栈，不因走代理放松；
- **SOCKS 代理**：明确不支持并显式拒绝，绝不把 SOCKS 凭据错当 HTTP 认证发出。

## 控制交互：显式「确认修改」

供应商 / 模型 / 思维档位的下拉现在**只改本地待选**，点「确认修改」才提交一次配置
变更——生效时间点一目了然。弱网下提交失败时待选值保留，直接再点确认即可重试，不再
出现「下拉被拉回、好像没选上」的困惑。协作模式保持原有的「应用模式」交互。

## 修复

- **send 首验在 Windows 上恒超时**：该版本宿主的状态更新不带日志序号，「最后一条
  用户消息指纹变化」判据恒假。现补一条等价因果证据（回执 inputId 与回合终态
  inputId 精确对拍），首次使用确认可以正常转正。
- **打断不落账**：本地队列的打断（含插队打断）此前绕过确认登记，打断能力永远拿不到
  实机证据；现已补齐登记与确认窗重置。
- **慢 token 吃光连接预算**：长连接升级预算改为取到一次性令牌之后再起算，令牌慢一次
  不再导致直连与兜底全部零预算直接离线。

## 其他增强

- **用量**：新增 tokenizer 估算查询模式、仪表盘页签与手动更新；内置 o200k_base 离线
  参考 tokenizer；WorkBuddy 突发投递的观察不再混入流式 TPS，中文日志前缀可解析。
- **看板精度**：会话「内容更新」与「进程在线」分离计时（SessionAges），WorkBuddy
  心跳不再错误延长完成冷却。
- **设置页**：分区层级与编号统一，远控分区重排。
- **界面**：首页「清除已完成」与通知铃的计数徽章统一外形；ZCode 控制错误提示附带
  具体原因码，不再所有错误一句「暂不可用」。

## 升级须知

- **ZCode 能力首次使用会有一次有界确认**：升级后能力账本随版本识别自动重算，你第一次
  真实使用某项控制能力时，兔维斯会等宿主状态前进（≤5 秒）来确认可用——绝不重发、
  绝不发测试消息；确认成功即转正，之后不再重复。
- **Windows 代理用户**：系统代理开着但隧道不通时，授权与连接会自动改走直连（不再需要
  手动关代理再试）；直连不通但代理可达时，长连接自动经代理隧道。SOCKS 代理不支持。
- **模型 / 思维档位切换改为显式确认**：下拉选完不会立即生效，点「确认修改」才提交；
  失败时待选保留，可再点重试。
- **ZCode 待发队列面板只在还有可见消息时显示**；打断 / 插队后的暂停语义不变——之后
  新排队的消息仍需手动点「继续队列」才会发出。
- 官方队列级命令（在 ZCode 自己的队列上撤回 / 立即执行 / 恢复自动排水）在未取证的
  ZCode 版本上按证据闸关闭；本地待发队列不受影响。

## 已知边界

- **ZAI 通道**：只有源码与模拟证据，官方 live 未验证，本版暂不开放该通道授权。
- **审批应答（Windows）**：实机会话未构造出审批卡（完全访问模式无卡），该能力在本
  平台待后续验证。
- **官方队列恢复**：在未取证 build 上保持关闭；若 ZCode 应用自己的队列被暂停，请在
  ZCode 应用内恢复后再使用兔维斯的队列功能。
- ZCode 升级后能力账本自动重算属预期行为（按 build 证据开闸），各能力会重新走一次
  首次使用确认。
