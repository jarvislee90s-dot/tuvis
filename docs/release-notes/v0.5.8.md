# v0.5.8 发布说明（2026-10-16）

> v0.5.7 正式版以来的全部变更：**tuvis-3D 3D 科技兔成为默认内置桌宠**、全域报错带错误码、
> 文件面板新增「会话产物」来源、codex 信任门改应用内常驻操作卡，以及针对安装包校验失败、
> 远程连不通误清配置、Windows 嵌套 skill 不可用等问题的修复。升级后无需任何手动配置。

## 新功能

- **tuvis-3D 内置桌宠（默认）**：全新的 3D 科技兔桌宠，带四组各四句原声语音（等待确认、
  任务完成、出错鼓劲、日常闲聊），首次使用默认选中、排在内置列表第一位；原来的小狐狸
  Foxbell 原样保留，一键即可切回。升级用户的既有宠物选择自动保留，旧版导入的同名外部
  宠物也不受影响。
- **报错全面带错误码**：应用内所有报错统一为「错误码 + 中英文案」，远程接入、注入、服务
  层、移动端网络等全部覆盖。以后反馈问题只需附上错误码，就能精确定位。
- **文件面板第四来源「会话产物」**：除了从对话里提取的文件路径，现在还会扫描会话正文中的
  产物链接与行内文件引用（代码块内外都认），自动并入文件面板同一份列表；白名单内的格式
  点击即可预览，桌面端与手机端一致。
- **codex 信任门改应用内常驻操作卡**：注册 codex 的 Hook 后，提醒不再是一条一闪而过的系统
  通知，而是应用内常驻的操作卡——不办就不消失，点「复制命令」或「不再提醒」才销账；卡面
  自带 `/hooks` 命令文本，剪贴板不可用也不碍事。信号健康度分区同时挪到设置页「工具与体检」
  块，未注册的工具会如实标注原因（如 macOS 上 kimi 显示「本平台暂不分发 Hook 通道」）。
- **工具徽标官方化**：DSH、Kimi、OpenClaw、WorkBuddy 等工具图标按官方源重绘，看板、设置、
  手机端设计语言统一。

## 修复

- **外部域名（免域名）安装包校验失败**：cloudflared macOS `.tgz` 的 sha256 期望值与上游
  发布清单错位，现已更正，安装向导可正常走完。
- **远程连不通时不再误清配置**：连不通类失败不再自动重置 Funnel——瞬时抖动 1–2 分钟自愈，
  好端端的配置不会被清掉重开；引导文案与诊断日志同步补齐。
- **Windows 嵌套 skill 不可用**：skill 标识斜杠口径统一，之前「导入必失败、重复卡片、绑定
  恒空」的嵌套 skill 全链路可用；存量数据自动迁移，无需手动处理。
- **注入安全加固**：禁注键黑名单上提到注入引擎入口，macOS 传统三通道同样受检，封住绕过
  缺口（#79）。
- **预设外链误报**：symlink HOME、macOS `/var→/private/var` 别名环境下不再把自建链接误报
  为外部链接（#64）。

## 升级须知

- **默认桌宠变为 tuvis-3D**：全新用户首次启用即 3D 兔；升级用户之前选的宠物（含 Foxbell
  或自定义宠物）自动保留，无需任何操作。想切换：设置 → 通知与桌宠 → 「切换宠物」。
- **宠物物理坠落每次重启应用后默认关闭**（会话内随时可再开，多窗口同步不变）。
- **看板筛选不再有 openclaw 档**：它不支持消息提醒；卡片徽章保留。如果你之前停在 openclaw
  筛选上，升级后会自动回落到「全部」。
- **Windows 嵌套 skill 的存量数据自动迁移**：首次启动自动完成，无需手动处理。
- codex 桌面 APP 会话的模式/权限/问答/审批动作目前仍会提示「开发中」——有意为之的临时
  限制，协议通道落地后会自动放开。
- 目前仅支持 Windows 与 macOS；Linux 尚未支持。
