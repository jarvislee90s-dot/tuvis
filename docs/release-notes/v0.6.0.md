# v0.6.0 发布说明

## 本版重点：Codex APP 手机端控制与消息、文件双向关联

Codex 桌面 APP 会话现在可以在手机上**查看并操作**，不再只是只读卡片。能力按 Desktop
build 精确解锁，实验性提供：

- **消息投影**：会话正文、Codex 运行状态、待处理请求与队列统一投影到手机详情页；
- **发消息与排队**：手机发送进入 Desktop IPC 动作账本，带 actionId 幂等；Desktop 忙时
  排队，不伪造立即送达；
- **command 审批**：手机端批准/拒绝 Desktop 的 command 审批请求；Unknown 结果不自动重投；
- **Plan 阻塞问答**：Desktop 的 Plan 阻塞式提问可在手机作答；
- **queue / exec 兼容路径**：Desktop 在场走 queue；Desktop 缺席且 H3 开启时走兼容 exec；
  H3 关闭时如实拒绝，不静默改道；
- **生成图入文件池**：`~/.codex/generated_images/<threadId>/` 下的 Codex APP 生成图以
  「会话产物」进入文件面板，和普通产物一样可预览。
- **正文文件引用与结构化产物**：正文中已有识别能力的文件路径可直接打开预览；上传／引用图片、生成图、文件修改和查看作为结构化产物显示，并标注真实来源。文件项可跳回最近一次正文引用，搜索范围为当前消息尾窗和最多四页更早消息（每页最多 50 条）。
- **始终预览文件当前内容**：同一路径内容更新后，已有正文链接仍打开磁盘上的当前文件；产品不保存或回放历史文件版本。

**解锁范围（不对外泛化）：**

| 平台 / Desktop build | 已解锁 | 未解锁 |
|---|---|---|
| Windows `26.1013.4894.0` | 发送 / 状态 / command 审批 / Plan 阻塞问答 | permissions（保持关闭）；真实手机 PRODUCT 验收未完成 |
| macOS `26.1013.40934` | 发送 / 状态 | command 审批 / Plan 问答 / 真实手机主路径 |

其他 build 不宣称支持；未解锁能力按既有失败契约如实拒绝，不伪造审批或空会话。

## Token 看板 V2

本版同时交付 Token 用量看板 V2：供应商显示名、models.dev 自动定价、
API 等效费用、原生人民币价与当日汇率、记录页渠道展示收敛。Token 口径、采集器与历史账本
零改动，升级后无需手动迁移。

### 新功能

- **Token 看板 V2**：A 总览固定展开，统一为「新增输入 / 缓存命中 / 未缓存命中 / 输出 /
  命中率 / 请求次数」；B 用量趋势支持卡内「全部 / 按工具 / 按渠道」局部筛选，峰值与环比
  同口径且不影响全局；C 用量分布支持渠道 / 工具 / 项目 / 模型四维切换，默认 Top 5 并显示
  缓存命中率；D 费用卡改为每条模型一张卡片、默认展开，卡内展开「新增输入 / 缓存命中 /
  输出 / 合计」×「Token 用量 / 金额 / 单价」明细。
- **供应商显示名（别名）**：非空 provider 可按原始串映射为可读显示名，空 provider 的
  「工具 + 模型」条目可逐条命名；不同原始串可映射到同一显示名并跨工具合并，保存后回溯
  生效。别名只影响展示与分组，不回写账本、不改变 Token 口径。
- **自定义价格规则（固定价 / 分时价）**：配置弹窗「自定义价格规则」支持固定四价，或按周一至周五的多个高峰窗口
  （整点、可跨午夜）使用高峰四价、其余时间使用低谷四价；低谷留空分量回退目录价；时区可选上海 / UTC / 系统本地
  （只影响 API 计费峰谷计算）；提供「按高峰 × %」快捷填充。存在分时规则时按小时桶判定峰谷后汇总，单价为加权平均；
  日聚合回退时按低谷价估算并标注。
- **API 等效费用与自动定价**：接入 models.dev 公开价目，按「直营官方（含中国站变体）>
  OpenRouter」精选来源自动匹配；支持目录搜索、计价身份显式指定、自定义价格规则（固定价 / 分时价，USD / CNY）；费用行展示参考来源、模型发布日、快照获取时间与不准确原因。
- **原生人民币价与当日汇率**：解析 models.dev 源 TOML 中明确写出的人民币四价，USD / CNY
  各自优先原生价；缺失侧按当日 USD→CNY 汇率换算并逐分量标记，换算金额 / 单价加虚线下划线。
- **费用按小时明细计价**：近 7 天 / 30 天 / 自定义（≤31 天）改按小时明细聚合，dsh 也能按
  输入 / 缓存命中 / 输出全价估算；明细缺失时整段回退日聚合并如实披露。
- **独立费用 CSV**：导出当前时间窗全部渠道 / 模型费用行，不含总计；在既有 17 列后追加
  渠道键 / 渠道类型 / 显示名 / 归一化模型 / 目录发布日期 / 覆盖价标记 6 列。
- **共用的显示与计价配置弹窗**：设置页「用量统计」的「打开配置」与费用卡「管理配置」
  打开同一个弹窗；上半是供应商 / 模型条目（供应商名、模型名、计价身份），下半是可折叠的
  「自定义价格规则」。每个高级选项旁有 Info 悬浮说明；每条模型提供
  「覆盖此模型价格 / 编辑覆盖价」快捷入口，自动预填原始模型名，已有覆盖显示
  「已应用自定义价格」徽标。
- **记录页渠道展示与入口收敛**：记录页行名改为**供应商显示名优先**（「显示名 / 原始模型」；
  无别名回退原始「供应商 / 模型」，原始身份保留在 tooltip 与行数据中）。普通行不再显示
  「指定渠道 / 修改关联」，只有含糊行保留「绑定计费归属」；旧版计费归属与参考价规则收进
  记录页页脚的「高级」入口。

### 改进

- **自动匹配精简**：精选来源改为「直营官方（含中国站变体）> OpenRouter」，移除 Ollama Cloud 与
  `zhipuai-coding-plan`；四价全 0 的候选自动跳过，手动显式选择 0 价仍保留。
- **配置弹窗交互**：可点击内容统一为有边框的输入/按钮，新增只读 / 可编辑 / 已修改图例；改过的供应商名、
  模型名与计价身份用琥珀色标识；模型条目支持按用量 / 原始供应商名 / 原始模型名三键升降序排序；弹窗初始宽度
  1040px、最小 840px，与主看板窗口一致。
- **设置与文案**：明细保留期上限收紧为 90 天；工作小结明确只统计会话数与工具调用次数，不再提 Token 合计；
  定价目录状态移除重复的覆盖价迁移提示；数字设置改为失焦 / Enter 提交，修复保留期只能输入 9 或 90 的问题；
  用量设置卡头说明不再写死「8 项」。
- **D 卡**：默认展开、可折叠；卡头新增「同步价格」，可手动强刷 models.dev + 人民币来源 +
  当日汇率；表头币种 USD / CNY 快捷切换，账本与 CSV 仍按 USD 保存。
- **配置与别名同步**：记录页别名浮窗与配置弹窗写同一张供应商别名表并共用失效链，同一窗口
  内保存后行名与看板立即更新；设置页与 D 卡是两个 WebView，设置页修改后已打开的看板不保证
  立即刷新，看板内配置是主路径。
- **文案去歧义**：别名层统一称「供应商显示名 / 供应商别名」，计费绑定层统一称「计费归属」；
  旧版管理器更名为「计费归属与参考价规则」。
- **无障碍与交互**：配置弹窗打开时初始焦点落在标题，避免 Info 说明浮层自动弹出并吞掉第一次
  Esc；折叠头与入口按钮补齐 `aria-expanded` / `aria-controls`，模型输入改用显式 label 关联。

### 升级须知

- **无需手动迁移**：新增表均为幂等建表；既有供应商别名、计价身份、自定义价格规则与计费绑定原样
  保留，旧账本逐值不变。
- **Token 口径不变**：仍为 `requestTotal + output`；七个采集器、DeltaBuilder、游标语义、
  去重键与历史账本零改动。
- **记录页显示口径变化**：有供应商别名的行，行名会从原始「供应商 / 模型」变为「显示名 /
  原始模型」；原始身份仍保留在 tooltip 与行数据中，不影响导出、筛选或计费绑定。
- **计费入口变化**：普通行不再出现「指定渠道 / 修改关联」；需要拆分同一原始 provider 串的
  两个订阅时，使用含糊行的「绑定计费归属」或记录页页脚「高级：计费归属与参考价规则」。
- **币种与价格**：显示币种可切 USD / CNY；自定义价格规则按所选币种存储，另一币种按当日汇率换算
  并加虚线下划线。价格只用于估算，不是实际账单。

### 已知限制

- 同一原始 provider 串对应两个订阅时，供应商别名无法拆分，仍需显式计费绑定；Token 不会按
  比例拆账。
- 自定义价格规则按归一化模型名全局生效，不支持按渠道分别定价。
- 条件价（多模态 / 上下文阶梯）按基础文本价估算，并在「不准确原因」中标注；缺价显示 `—`，
  不显示 0。
- 单次刷新最多拉取 32 个人民币来源目标（按近 7 天用量排序），超出部分按当日汇率换算。
- 设置页与 D 卡跨 WebView 的即时联动尚未实现；本轮以看板内联配置为主路径。

## 升级须知

- **Codex APP 远程控制是实验性能力**，且按 Desktop build 精确解锁；升级后若你的 Desktop
  版本不在上表，仍会看到“未解锁/开发中”的如实提示。
- **permissions 仍未开放**：即使 command 审批可用，也不代表权限档可远程切换。
- **明细保留期上限收紧为 90 天**：存量设置大于 90 天会在读取时收敛为 90，下一次采集会按 90 天
  清理更早的小时明细；永久保留的日聚合不受影响。需要更长小时明细请在升级前导出。
- **消息签名开关行为变化**：Codex APP 路径默认**不带** `[mobile 花名]` 来源标记；需要时在
  电脑端「消息签名」中开启。既有 actionId 幂等语义不变。
- H3（无头兼容）默认关闭；开启前请阅读设置页安全说明。H3 关闭时 Desktop 缺席会如实拒绝，
  不会静默走 exec。
- 生成图进入文件池不改变“消息内嵌图”范围；正文仍不直接嵌入图片。
- 真实手机 / 双平台 PRODUCT 验收尚未全部完成；不要把自动化夹具结果当作全量真机通过。

## 已知限制

- Windows 只有 `26.1013.4894.0` 解锁 command 审批 / Plan 问答；macOS 当前只到发送/状态。
- 真实手机主路径、Desktop 重启恢复、queue/exec 双臂、Unknown 强杀恢复仍待用户在场验收。
