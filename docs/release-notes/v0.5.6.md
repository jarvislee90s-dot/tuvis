# v0.5.6 发布说明（2026-10-11）

> v0.5.5 正式版以来的全部变更：Codex 远程操控完整化（模式/权限切换、问答屏读全链、
> notes 备注三动作）、品牌视觉全套落地、审批卡防误触、Claude 多选卡补全。
> 升级后无需任何手动配置（hook 老路径自动迁移）。

## 品牌视觉

- **应用图标全套切换**：Windows / macOS 全尺寸应用图标随更名批统一为兔维斯视觉；
  远程看板品牌行、PWA 清单（manifest）同步换装。

## 新功能

- **Codex 模式/权限远程切换**：移动端「模式」组显示 计划/操作 两枚 chips——当前档
  高亮且不可点，点另一档即向终端发一次 shift+tab；「权限」组四档直选（只读/默认/
  自动审批/完全信任），完全信任保留二次确认。切换结果以终端屏读为准。
- **Codex 问答屏读全链**：多题问卷、单选、Other 备注全支持；末题归零闸 + 双条件
  提交闸防错交；滚回区残留面板防误读。
- **Codex 备注（notes）三动作 + 实时同步**：终端 note 行文字自动回填移动端输入框
  （翻页、每次动作后都重读）；发送（tab→核验→打字→核验→回车）、清空（tab 循环
  ≤2 下、每下读屏、字消失即停）、覆盖写入（清空+发送拼接）。
- **Claude 多选卡覆盖写入/清空**：已写入态出「编辑/覆盖写入/清空」（该键序
  2026-10-03 已实机定案，本次补上能力开关）。
- **审批卡防误触**：命中审批但读不到终端对话框时，「允许/拒绝」自动禁用并每 2.5s
  重读，读到选项才可用（多选问题面板不再可能被审批键误伤）。

## 修复

- **Codex 模式读反**：状态栏两行形态下「计划」被读成「操作」——双源判读修复。
- **Codex notes 链复活**：0.160.0 实测「备注不落卷」在 0.162.1 复验未复现；恢复远程
  自由作答，并按实测语义重写（旧版会静默丢用户文字的两处竞态一并修复；核验失败改为
  静默刷页对齐，不再弹红错）。
- **数字开头的备注不再失明**：「3 点建议」这类以数字开头的备注此前被误判为选项行
  跳过——排除判据与选项行解析器同源后照常读出。
- **Claude 多选面板误读为审批框**：选项带复选框记号的面板不再出「允许/拒绝」
  （claude 2.1.287 待答问题不落 transcript 的版本漂移另行登记 issue #140）。
- **hook 改名迁移自愈**：从更名前版本升级的用户，旧 `~/.mam` 路径 hook 条目启动时
  自动改写为 `~/.tuvis` 新规格（此前会持续报 hook error 且问题卡静默失效）；
  codex hooks.json 带 BOM 时注册失败也已兼容。
