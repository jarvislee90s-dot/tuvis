# v0.6.3 发布说明（草稿）

> v0.6.2 正式版以来的全部变更：**桌面四页同窗**（消息看板 / 工具资源 / 模型用量 / 输出速度
> 同窗切换）、**输出速度双指标页**（流式 TPS + 含等待响应吞吐，七源接入）、**近期 TPS 短时
> 抽样**，以及 WorkBuddy 数值兼容修复、Codex 响应观测接入、深色配色修订与五轮实机反馈打磨。
> 状态：**未发布草稿**，随下一个版本发布时定稿。

## 升级须知

- **主窗口默认尺寸调整为 900×750**（最小仍 800×600）：横向比例下速度看板的左列表与右侧
  图表互不挤压；已手动调整过窗口大小的用户不受影响。
- **深色配色修订**：深色主题由雾银纯灰改为**冷石墨底 + 靛蓝/紫罗兰强调**；弹窗改为实心
  卡面并整体上调字号（修复高分屏弹窗发糊）。浅色主题为纯白底 + 蓝紫强调，本次不变。
- **升级后 TPS 数据自动恢复**：WorkBuddy Mac 用户若旧版本漏采了近期速度记录，升级后首次
  采集会自动有界恢复最近 24 小时的记录并去重——只影响速度数据，不动 Token/费用账本。

## 新功能

- **桌面四页同窗**：主窗口四个一级页签——消息看板 / 工具资源 / 模型用量 / 输出速度；
  切页保留各页状态、不停止会话监控与通知；旧独立用量窗口入口（标题栏按钮 / 桌宠迷你条 /
  `/usage`）统一唤起主窗口并选中对应页签。
- **输出速度双指标页**：流式输出速度（TPS，不含首 Token 等待）与响应吞吐·含等待
  （Token/s）两条独立口径，四档区间（15 分钟 / 1 小时 / 5 小时 / 24 小时，默认 5 小时）
  分桶图 + 四格指标（速度 / 首Token平均等待 / 累计用时 / 工具累计用时）；悬停读数、点击
  固定快照；详情组合名为下拉可选框，列表组合名悬浮即时显示全名；空桶不画 0、不推算。
- **近期 TPS 短时抽样**：近 2 分钟 / 10 分钟 / 1 小时 / 当天采样吞吐（输出速度页继承其
  口径原则；本条与上一条同属输出速度能力的组成部分）。
- **七个来源接入双指标**：DSH / ZCode / Kimi / WorkBuddy Mac / Claude / OpenCode 双指标
  各有有效子集；**Codex 接入日志近似的响应吞吐**（显著标注「含等待 · 日志近似」；流式与
  逐响应首Token等待如实缺省）。全部为本机端侧采样，不发送任何测速请求。
- **用量导出图可选模块**：「导出设置」勾选分组分布四种维度（可多选）、API 等效费用、
  工作小结 + 桌宠发言；总览 + 趋势图必选；只影响导出图片，复制文本不变。

## 修复

- **WorkBuddy 速度记录恢复**：日志数值为字符串形态时旧解析器整源跳过——现已兼容接纳
  （拒绝非法形态并诊断，不默认 0）；旧游标越过记录自动有界恢复、去重、失败批不推进。
- **Codex 响应观测**：原生 response_id 对齐去重（跨文件 / 复制历史只计一次）；工具与生成
  交错、失败 / 取消 / 无法归属的片段不出数，不用整轮耗时补洞。
- **界面打磨（五轮实机反馈）**：会话卡三行紧凑排版（会话名加粗、行距 8px）；弹窗实心卡面
  + 字号上调（修复高分屏弹窗发糊）；按钮 / 输入框 / 卡片边缘在浅深两主题下清晰可辨；
  「兔维斯 仓库」看板与主看板面板统一；用量页头工具栏并为一行、页脚口径行移入分享图。

## 已知限制

- 速度为**端侧采样，非全量监控**：只统计已采集的有效调用，空窗不补 0。
- Codex 暂无流式速度与逐响应首Token等待（日志近似口径，如实标注）。
- 工具累计用时暂无可靠归属来源，显示「—」（全工具统计见「工作活动」）。
- Windows 平台的 TPS 验收留待最终平台验收；真机验证覆盖以发布验收为准。
