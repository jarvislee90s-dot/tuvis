# v0.6.3 发布说明（2026-10-28）

> 本版**重磅：Codex 桌面端自适应控制**。手机端不再依赖整 build 白名单，而是按操作
> 契约证据分别放行；同组异步题一张卡、一次提交。另含主窗口四页导航、输出速度双指标
> 与横竖屏默认布局。升级后数据与既有设置保留。

## 重磅：Codex 桌面端自适应控制

- **按操作放行**：普通消息、阻塞问答（多题 / 多值 / 自由文本）、命令与文件审批
  （批准 / 拒绝 / 终止本轮）、定向打断、空闲异步答题分别判断；桌面版升级后通常无需
  等待版本登记。
- **同组异步题一张卡**：逐题填写，上一题 / 下一题保留草稿，最后一题一次提交整组；
  已答组自动核销，刷新不复活。选项与自由文本互斥，不会提交界面上看不见的答案。
- **队列暂停保护**：打断或终止后待发队列保持暂停，由你选择「恢复队列」或「本条先发送」；
  普通刷新不会删掉暂停。
- **交互卡**：审批红、问答蓝；只停靠当前可答或本机发出过动作的组，其余收为一行。

## 兼容机制设计

Codex 桌面端能力按**证据等级**放行，而不是猜协议或按版本号硬编码：

| 证据 | 放行范围 |
| --- | --- |
| shipped / 当前包契约匹配 | 普通发送、问答等可安全尝试的操作 |
| 本机真实成功 | 需要确认结果的发送与答题 |
| 只读探测 + 契约证据 | 打断、命令/文件审批等破坏性操作 |
| 无匹配 | 如实关闭并说明原因 |

未知 Desktop 版本默认开启自动适配，但只在目标、状态与协议守卫全部满足时发送普通消息；
破坏性操作不随自动适配默认开启。**Desktop 会话永不自动转 headless**，未送达就是未送达，
不伪造成功。适配详情可查看每项证据并随时关闭自动适配。

## 适配边界（如实申报）

- **完美适配**：契约匹配且本机实测通过的发送、阻塞问答、同组异步提交；macOS
  `26.1021.31345` 已探针取证。
- **兼容适配**：未知 build 的普通发送按守卫尝试；审批 / 打断仍需证据，可能保持关闭。
- **不支持**：Plan 模式审批、permissions 权限切换、无活动回合的打断。请到 Desktop 处理。
- **待验**：Windows 实机、360/390 像素截图、原生成功强关联（当前不把原生完成当成功证据）。

## 同时发布

- 主窗口四页导航（消息 / 资源 / 模型用量 / 输出速度），各页保留状态；
- 输出速度双指标页：流式 TPS 与含等待响应吞吐，四档区间、来源如实标注；
- 手机会话详情横竖屏自适应默认布局。

## 升级须知

- 未知 Desktop 版本默认开启自动适配；不需要可在「适配详情」关闭。
- 队列暂停是保护机制；打断前请确认桌面侧没有未完成的工作。
- Plan 模式与 permissions 仍不开放；远程不伪造审批或计划决策。
- 目前仅支持 Windows 与 macOS，Linux 尚未支持。
